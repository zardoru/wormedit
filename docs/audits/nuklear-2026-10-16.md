**Verified policy matrix (preserve):**

| Owner | Identity / extra gates | Threshold/release/click behavior |
|---|---|---|
| Timing marker | capture project/chart/revision; focus, scene, occlusion, timing lock, overflow | Latches vertical 4 px threshold including release; emit group move only after threshold, otherwise consume. |
| Bookmark | chart/revision + focus/scene/occlusion/overflow locally; project change handled by outer reset | Latches vertical 4 px only on held updates; release uses prior active flag; a click can replay note-paint begin/release (`:903–930`). |
| BGA | capture project/chart/revision; resource pointer mode off, focus/overflow | Horizontal or vertical threshold; a click can open overlap stack; moved release emits BGA move. |
| Fit/offset-fit | capture + runtime-active; focus/overflow/timing lock, offset also audio-offset lock | Threshold checked at release position, not a latched moved bit; below threshold cancels. Modifier-only changes may emit updates. |
| Beat zero | capture project/chart/revision/audio asset/rate; total frames, overview left/width, availability and runtime state | Horizontal threshold at release; below threshold cancels; separate audio-offset action channel. |
| Timing stage | capture + runtime existing stage object; focus/timing lock; lost button | Moves stage while held beyond threshold with motion; release only clears UI capture, does not commit stage. This local continuation has no explicit overflow check. |
| Audio Slices offset | chart/revision/asset/frames/rate; outer `cancel_stale_offset_drag`, focus/input gating/escape/cancel | Shift begins; release commits without a movement threshold; lost button cancels. Captured frames-per-pixel determines delta. |

**Owner/target.** Extend the existing UI capture owner with a typed stack decision; pass domain/source validity and named release policy without stored callbacks. Keep core gesture/proposal runner validity separate. Illustrative existing-marker emitter:

## Necessary immediate-mode complexity and rejected over-unification

- Explicit Nuklear begin/end, layout row consumption, widget bounds queried before allocation, clip/scissor restoration and style-stack balance are real protocols. Keep call order; a “render anything” callback does not improve ownership. `render_compose_dock` already shares dock framing (`compose_panel.cpp`); do not create another dock shell.
- Keep the **15 list sites** distinct by data contract: sound grouped/slot/flat projections, BGA search projection, inline overlap filtering, audio catalog, notifications, project charts and measure selection have different row windows and activation semantics. Share only demonstrated geometry/facts, never a virtual row adapter per panel.
- Keep custom canvas rendering (`compose_canvas.cpp`) separate from native widgets: editor-pixel vs screen-pixel scaling, downscroll, clipping and per-kind glyphs are domain rendering. Repeated draw calls alone do not justify table-driven type erasure.
- Shared popup primitives are already present; inline bookmark/note/section label rendering is already one implementation. ContextMenu owns keyboard selection, opening-press survival and delayed retirement; Dialog owns top-level modal surfaces. Neither is a transparent wrapper.
- Keep release latches even after a popup closes: they prevent click/key release leakage into the canvas. Escape/text/all quietness are intentionally different; command menu's all-button/scancode handling is not interchangeable with two-button popup quietness.
- Keep tooltip placement/wrap/occlusion in `tooltip.cpp`, form aspect margins in `content_margin.h`, UTF-8 text fit/wrap in `text_fit.h`/`text_layout.h`, action stamps/slot arbitration in `compose_action_stamp.h`. Old D18 overlong-word lead is already addressed there; no new parsing/geometry copies are justified.
- Keep small row-specific painters and guards that express domain policy; do not inline to meet a line-count goal or fragment further for complexity. Existing nested disabled scopes (e.g. `compose_layers_panel.cpp:347–348`) prevent blindly migrating every disable pair to a different widget implementation.
- Keep flat frontend view projections for embedded waveforms (`metadata_audio_section.cpp:56–75`) and field-by-field actions. Different view contracts are not a reason to merge ABI types or carry owning C++ values across C.
- Keep OS file-dialog completion boundaries, mutex/generation state and multiselect semantics. BGA multiselect picker is not a drop-in use of single-choice `file_dialog_slot_t`; an asynchronous shell migration needs its own policy inventory.
