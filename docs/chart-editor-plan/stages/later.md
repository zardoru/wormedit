# Implementation stages 6–8: later work

[Back to the implementation-stage index](../stages.md).

## 6. Editing depth and performance

- Add batch transforms, reusable quantization presets/reports, timing shifts, lane remapping, label search, and audio-clip reuse tools.
- Profile large charts and long compressed audio; bound memory use and keep decode/analysis work off the UI thread.
- Add cancellation and progress reporting for imports, waveform generation, validation, and export.

## 7. Deferred storyboard and scripting authoring

- Parse standalone `.osb` files and difficulty-specific storyboard content from `.osu` `[Events]` into a shared storyboard model while retaining unknown text losslessly. Preserve OSB loop commands as explicit nodes with source order, loop start, iteration count, and child commands in their relative-time domain; nested/adjacent loops and seeks must evaluate without eagerly expanding an unbounded command list. The bounded headless foundation parses/emits Sprite transforms and nested loops, canonicalizes valid command shorthand, evaluates all standard easing IDs, retains unsupported directives, compiles bounded root envelopes, and provides binary-seek/head-only schedule consumption. Structured standalone models now persist through native `storyboard_document_t` and its version-1 JSON codec, including bounded validation and compatibility with older raw-line storyboard records. The osu!mania adapter now imports and emits difficulty-specific Sprite blocks, nested loops, and retained unknown storyboard lines through that model, with bounded transactional parsing and semantic re-import checks. Until storyboard documents carry chart ownership, export rejects them from multi-chart songs. Animation headers and standalone parameter/sample directives remain opaque retained lines; trigger blocks with nested commands reject because their hierarchy is not modeled. Animation/sample normalization and rendering remain.
- Implement the Premake-style [OSBX Lua DSL](../../osbx-draft-spec.md), including separate storyboard/chart modules, stable IDs, multiple difficulties, groups, 2D affine matrices, ordered compound transforms, reusable clips, and OSB compatibility diagnostics.
- Activate the Storyboard workspace tab and build an osu!-style canvas and keyframe timeline editor for sprites, animations, samples, hierarchy, layers/draw order, origins/pivots, transform stacks, property tracks/easing, loops, triggers, and variables.
- Preview storyboards through the same sample-frame transport clock and deterministic scene evaluator used by offline rendering, including Pass/Fail-state simulation and optional chart overlays. Materialize each frame/window through the bounded reusable dynamic arena described above, with deterministic allocation order and no persistent pointers into reset storage.
- Emit standalone `.osb` files and embedded difficulty-specific `.osu` events, including native OSB loop blocks with correct indentation, relative child timing, iteration counts, and stable source/draw order. Preserve representable loops structurally; only flatten under an explicit bounded compatibility transform with a size/loss preview. Verify semantic emission/re-import against the shared evaluator.
- Embed a cross-platform Lua runtime for pattern generators after defining a versioned scripting API.
- Add cross-platform MIDI parsing and import MIDI files as stable project assets.
- Give Lua scripts read-only access to selection, measures, timing, lane profiles, storyboard assets/nodes, imported MIDI data, and deterministic seeded randomness. Scripts may emit chart notes/layers, OSBX objects/keyframes, or both in one proposed command batch.
- Add durable deterministic parametric recipes for SV, `SCROLLS`, and `SPEEDS`, including snapped draggable intervals, linear/exponential helpers, finite two-region bumps, explicit zero-width impulses, stable multiplicative overlap composition, fixed/adaptive export-only sampling, and an ordered post-process pipeline with optional normalization that preserves integrated scroll displacement or distance over the segment. The first core slice now persists exact editable recipes without sampled points, accepts older native projects without the field, compiles transient fixed/adaptive previews over the authored baseline with multiplicative overlap and half-open boundary ownership, and provides revision-checked snapped preview/commit dragging for start, end, and whole-span handles. A revision-bound draft layer now previews a new recipe appended in composition order or substitutes an existing recipe at its stable slot without mutating/copying the document, then Apply publishes one command and Cancel discards it. The Timing pane arms Scroll/SV-lane area selection, snaps and reselects the transient interval, edits exact constant/linear/exponential/bump plus fixed/adaptive and SPEEDS transition parameters, and draws bounded raw/composed curves. Interchange writers bake enabled recipes with each recipe's sampling configuration into detached chart copies: generic SV and StepMania `SCROLLS` map to instantaneous scroll events, `SPEEDS` maps to transition events, and only the copy loses the recipes. SSC and osu!mania serialize their supported baked events; formats that cannot represent the resulting ordinary event family diagnose that limitation explicitly. Impulses, normalization/post-processing, Lua generator/closure execution, and recipe-list/reorder/enable/duplicate UI remain.
- Allow note and storyboard modules to be included, evaluated, previewed, and exported independently. Let one project emit several named difficulties, including multiple charts collected into an SM/SSC file.
- Persist Lua generator recipes, inputs, parameters, seeds, hashes, and materialized note/storyboard output in the project; regeneration is always explicit and previewable.
- Add storyboard-to-video export behind an encoder interface. Evaluate linked FFmpeg libraries versus a packaged/discovered `ffmpeg` process for timestamped frames, audio mixing/muxing, cancellation, diagnostics, and cross-platform distribution.
- After that offline renderer and the live player preview are stable, add **Export player-preview video** to the area-selection context menu. Render precisely the selected chart interval through the same immutable player scene and sample-frame transport, with explicit output settings, cancellable bounded progress, temporary output, validation, and atomic publication.
- Add execution limits, cancellation, structured diagnostics, and explicit API-version compatibility. Pattern scripts should not mutate the live document directly.
- Add golden tests for bundled chart/storyboard generators, fixed-seed determinism, matrix/keyframe output, separate/combined modules, multiple difficulties, invalid script handling, API migrations, preview/apply/cancel, and undo/redo.

Exit condition: supported storyboard fixtures edit, preview, export to OSB, and render to video predictably; OSBX matrix/compound behavior follows its versioned specification; and bundled Lua generators produce identical chart/storyboard command batches on Windows, macOS, and Linux for a fixed document and seed.

## 8. Late format and gameplay compatibility

- Add Quaver reader/writer profiles only after its normative schema and current implementation behavior are captured in paired positive/negative fixtures.
- Add full StepMania roll authoring with a distinct hold subtype, visual skin, repeated-input preview behavior, target-profile serialization, and preservation of implementation-specific judgement/life settings.
- Add Pump-style ticked holds through chart-scoped tick-count timing segments, including a visible timing lane/editor, exact tick scheduling over hold intervals, gameplay preview, conversion diagnostics, and SM/SSC profile-specific read/write behavior.
- Keep ordinary holds independent from tick policy: changing a tick-count segment must not rewrite hold endpoints, and exporting to a target without ticked holds must preserve project data while producing an explicit loss/transform decision.
- Add deterministic tests for edits, same-position timing order, preview seeking, side-by-side comparison, copy/paste, undo/redo, and semantic export/re-import of rolls and ticked holds.

Exit condition: each promoted late adapter/gameplay profile has symmetric read/write coverage, deterministic preview semantics, and no unclassified loss.
