## T-554 Toggle playback assist ticks for semantic layers

- **Status:** done
- **Outcome:** Each Layers row has a default-off assist-tick icon. Selected layers click at tap/hold/roll/lift heads and BGM starts, including soundless objects. Chords/overlapping memberships produce one tick per source frame.
