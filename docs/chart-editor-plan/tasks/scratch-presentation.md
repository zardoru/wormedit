## T-526 Let skins suggest scratch sides and let users override the display

- **Status:** done (2026-10-11; verified; uncommitted follow-up)
- **Stale-plan audit (2026-10-11):** Scratch placement is currently authored in lane layouts. Field schemes color lane roles but cannot suggest display ordering; SP7 cannot preview the opposite scratch side through an independent appearance preference. A view-only ordering helper is needed across geometry and interaction paths.
- **Outcome:** A field skin can supply default scratch sides. BMSE defaults each side's scratch to the left for DP5. Appearance offers independent Single/P1 and P2 controls: Skin default, Chart layout, Left or Right. SP7 can preview a right scratch without changing note assignments or BMS channels.
