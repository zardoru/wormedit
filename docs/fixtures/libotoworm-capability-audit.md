# `libotoworm` capability audit (Stage 0)

Status: source audit of the sibling `../libotoworm` checkout and wormedit's current `src/common/chart.cpp` bridge. This is an implementation observation, not a format-conformance claim. Paths and line numbers refer to the checkout inspected for this audit; `libotoworm` is reference evidence, not the planned production codec.

## Boundary and verdict

`LoadChartFromFile` dispatches BMS-family files, BMSON, `.osu`, `.sm`, and `.ssc` to `libotoworm`, then converts only `song->charts.front()` into the legacy `Chart` maps. It copies song title/artist, channel count/class, positive BPM, warps, stops, interpolated speeds, and note start/duration/numeric sound IDs. It does not copy a `chart_document_t`, and it has no save/export path ([`src/common/chart.cpp:57-127`](../../src/common/chart.cpp#L57); legacy shape [`src/common/Chart.h:21-86`](../../src/common/Chart.h#L21)).

The table distinguishes what a loader can expose in its `ChartGroup`/`ChartTransient` output from what survives the bridge. “Parsed” below means the current loader code has a route for the field; it does not assert complete support for every dialect edge case.

| Family | Exposed by current loader | Survives current wormedit bridge | Important loader boundary |
|---|---|---|---|
| BMS/BME/BML/PMS | One chart, song title/artist, difficulty metadata, mapped note channels and holds, positive BPM, stops, scrolls, BGM/BGA events and filename tables, selected header metadata | Title/artist; channels/class; positive BPM and stops; each note's start, duration, and numeric sound ID | Raw commands and bytes, control tree, chart metadata, offset, scrolls, actual resource paths/events, BGA and BGM, note kinds and channel identities are not retained by the bridge; this loader does not populate warps or speed transitions |
| BMSON | One chart, metadata, measures, BPM/stops, notes, BGM, sound-channel filenames and derived slices; v1 BGA | Title/artist; channels/class; positive BPM/stops; note start/duration/numeric sound ID | Measure grid, source pulses/resolution, offset/provenance, sound channels, slice boundaries/continuations, resource paths, BGM/BGA, and extra metadata are discarded |
| SM | Song metadata and each `#NOTES` chart; BPM/stops, negative-BPM/negative-stop warp approximation, taps/holds/fakes | Title/artist; first chart's channels/class; BPM/stops/warps; note timing/duration | Notes are flattened to time; offset, source measures, step type/name/author/level, chart order beyond first, and source text are lost. No scroll/speed or delay ingestion here |
| SSC | Common song metadata, multiple `#NOTEDATA` charts, global or chart-scoped BPM/stops/warps/scrolls/speeds, notes | Same bridge fields as SM, including speed transitions; scrolls still omitted | Offset, per-chart fields and all unmodeled fields/source text are lost; delay timing is explicitly unimplemented in this loader |
| osu!mania `.osu` | A single mania difficulty, basic metadata, key count, notes/holds, BPM and inherited SV, generated sample names/events, background and retained non-sample event text | Title/artist; channels/class; BPM/scroll-derived speeds; note timing/duration/numeric sound ID | Audio-time note positions, offset, sample catalog and BGM, storyboard/event text, difficulty values, tags/bookmarks/effect bits, and raw timing points are discarded |

The bridge's specific projection is lossy even when the loader output is richer: `StoreNote` stores only positive `end_time - start`, clamps the sound ID to 16 bits, hardcodes `layer=0` and `volume=255`, and does not copy `NoteData::type` or `tail_sound` ([`src/common/chart.cpp:23-36`](../../src/common/chart.cpp#L23)). Timing events are copied into `std::map<double,...>` keyed by loader time, with BPM converted from beats/second to BPM and non-positive BPM skipped ([`src/common/chart.cpp:95-115`](../../src/common/chart.cpp#L95)). Equal-time values of the same event kind therefore collapse to one map entry; equal-time same-lane notes overwrite the lane's prior value at that row. Scroll events have no destination field or copy loop in `ChartSegment` ([`src/common/Chart.h:67-74`](../../src/common/Chart.h#L67)).

Extension matching is case-normalized. Unsupported extensions return `false`; accepted extra `.ft2` and `.ojn` inputs are outside this initial audit. The loader's exceptions are not translated to a diagnostic here, and only an empty/invalid first chart returns `false` ([`src/common/chart.cpp:15-20`](../../src/common/chart.cpp#L15), [`src/common/chart.cpp:57-83`](../../src/common/chart.cpp#L57)).

## Format observations

### BMS, BME, BML, PMS

- The loader reads one file as one difficulty, detects PMS from the filename, detects UTF-8/BOM versus a Shift-JIS fallback from at most the first 1024 bytes, converts command content, and parses the resulting text ([`../libotoworm/src/note_loader_bms.cpp:906-999`](../../../libotoworm/src/note_loader_bms.cpp#L906); detection [`:823-835`](../../../libotoworm/src/note_loader_bms.cpp#L823)). The original bytes, chosen encoding, line endings, comments, and source spelling are not attached to the produced chart.
- It recognizes title/artist, genre/subtitle, initial BPM, music/preview, offset, stage/background image, difficulty, level, maker, judge rank/total, LNOBJ, WAV/BMP tables, indexed BPM/STOP, extended BPM, and indexed SCROLL directives ([`../libotoworm/src/note_loader_bms.cpp:1031-1153`](../../../libotoworm/src/note_loader_bms.cpp#L1031)). Unknown non-event commands fall through without storage. Although BMS channels `SP` and `SC` are classified in the parser, only the SCROLL channel is processed here; no speed-channel event pass exists ([`../libotoworm/src/bms.cpp:463-477`](../../../libotoworm/src/bms.cpp#L463), [`../libotoworm/src/note_loader_bms.cpp:711-721`](../../../libotoworm/src/note_loader_bms.cpp#L711)).
- Event decoding recognizes BGM `01`, measure ratio `02`, direct BPM `03`, BGA base/poor/layers `04/06/07/0A`, extended BPM `08`, and STOP `09`; playable-channel ranges cover P1/P2 visible, long-note, invisible, and mine channel families ([`../libotoworm/src/bms.cpp:463-517`](../../../libotoworm/src/bms.cpp#L463)). Measure fractions and non-4/4 BMS measure ratios affect the computed beat positions ([`../libotoworm/src/note_loader_bms.cpp:228-250`](../../../libotoworm/src/note_loader_bms.cpp#L228), [`:679-708`](../../../libotoworm/src/note_loader_bms.cpp#L679)). LNOBJ endpoints and channel-based long notes are paired into time-duration notes; the mine callback constructs a value but never appends it to the measure, while invisible notes are appended as `NK_INVISIBLE` ([`../libotoworm/src/note_loader_bms.cpp:349-445`](../../../libotoworm/src/note_loader_bms.cpp#L349)).
- WAV paths are retained only for used sound IDs; BGM channel events are separate autoplay events. BMP IDs/paths and timed BGA layers are retained in transient data. These are all lost at the wormedit bridge except numeric note sound IDs ([`../libotoworm/src/note_loader_bms.cpp:516-529`](../../../libotoworm/src/note_loader_bms.cpp#L516), [`:735-762`](../../../libotoworm/src/note_loader_bms.cpp#L735), transient fields [`../libotoworm/include/ChartGroup.h:184-210`](../../../libotoworm/include/ChartGroup.h#L184)).
- The syntax tree recognizes `#RANDOM`, `#IF/#ELSEIF/#ELIF/#ELSE/#ENDIF`, `#SWITCH/#CASE/#DEF/#SKIP/#ENDSW`, and stores `#SETRANDOM` as a raw line ([`../libotoworm/src/bms.cpp:151-353`](../../../libotoworm/src/bms.cpp#L151)). But the file loader immediately evaluates the tree and dispatches only the resulting command list; `tree::evaluate()` constructs a default-seeded RNG ([`../libotoworm/src/note_loader_bms.cpp:1173-1177`](../../../libotoworm/src/note_loader_bms.cpp#L1173), [`../libotoworm/src/bms.cpp:610-616`](../../../libotoworm/src/bms.cpp#L610)). The selected projection is deterministic for this implementation and the source tree is not attached to the chart. `#SETRANDOM` is not interpreted as evaluator state, and switch evaluation selects one matching case/default without preserving fallthrough; `#SKIP` is parsed as a break child that evaluation ignores ([`../libotoworm/src/bms.cpp:151-155`](../../../libotoworm/src/bms.cpp#L151), [`:394-459`](../../../libotoworm/src/bms.cpp#L394)). This is a useful syntax reference, not a complete control-flow implementation.

### BMSON

- The loader accepts the unspecified/legacy `0.21` shape and explicit `1.0.0`; other explicit versions throw. It maps known mode hints and generic/special key counts, reads metadata, source resolution, optional `lines`, BPM events, stop events, and sound channels ([`../libotoworm/src/note_loader_bmson.cpp:28-53`](../../../libotoworm/src/note_loader_bmson.cpp#L28), [`:109-226`](../../../libotoworm/src/note_loader_bmson.cpp#L109), [`:247-340`](../../../libotoworm/src/note_loader_bmson.cpp#L247)). Only the first chart output is imported by wormedit.
- Sound-channel notes are stable-sorted by pulse, mapped from source lane x, and emitted as playable notes or BGM. It derives measure lengths from `lines` (using 4-beat fallback behavior when later assigning notes), then converts pulse positions through timing to seconds ([`../libotoworm/src/note_loader_bmson.cpp:247-297`](../../../libotoworm/src/note_loader_bmson.cpp#L247), [`:504-537`](../../../libotoworm/src/note_loader_bmson.cpp#L504), [`:635-670`](../../../libotoworm/src/note_loader_bmson.cpp#L635)). Thus the bridge loses the exact pulse grid, source resolution, and authored measure geometry.
- Slice derivation is transient, not a rendered audio edit: each sound channel gets a numeric ID and cleaned filename; non-continuation events restart at source time zero, continuation events begin at the running prior endpoint, and the next event supplies an end boundary when present (otherwise the end is open) ([`../libotoworm/src/note_loader_bmson.cpp:382-447`](../../../libotoworm/src/note_loader_bmson.cpp#L382), [`:462-479`](../../../libotoworm/src/note_loader_bmson.cpp#L462)). Same-lane/same-pulse events merge into an existing note's slice table, with code comments saying overlapping slice assignment keeps the last declared slice. Consecutive BGM continuation entries are joined ([`../libotoworm/src/note_loader_bmson.cpp:415-445`](../../../libotoworm/src/note_loader_bmson.cpp#L415), [`:481-502`](../../../libotoworm/src/note_loader_bmson.cpp#L481)). The loader copies slice data into `ChartTransient::slice_data`, but the bridge drops it ([`../libotoworm/src/note_loader_bmson.cpp:697-707`](../../../libotoworm/src/note_loader_bmson.cpp#L697)).
- BGA is loaded only for v1.0.0 into image and timed-layer data; legacy `0.21` BGA is explicitly unsupported ([`../libotoworm/src/note_loader_bmson.cpp:539-615`](../../../libotoworm/src/note_loader_bmson.cpp#L539)). Metadata includes fields beyond title/artist, such as subtitle, preview music, level, chart name/author, back/eyecatch image, mode hint, resolution, judge rank and total; the bridge retains only song title/artist and lane count/class ([`../libotoworm/src/note_loader_bmson.cpp:167-226`](../../../libotoworm/src/note_loader_bmson.cpp#L167)).

### StepMania `.sm` and `.ssc`

- `.sm` collects song-level BPMS/STOPS/OFFSET and emits a chart for each `#NOTES`; it turns negative stops and negative-BPM timing sections into time-domain warp approximations ([`../libotoworm/src/note_loader_sm.cpp:676-757`](../../../libotoworm/src/note_loader_sm.cpp#L676), [`:582-674`](../../../libotoworm/src/note_loader_sm.cpp#L582)). Its note parser supports the enumerated step types, taps, hold heads/releases, and fake `F`; hold and roll symbols `2`/`4` share a path, so the source subtype is not modeled distinctly ([`../libotoworm/src/note_loader_sm.cpp:18-52`](../../../libotoworm/src/note_loader_sm.cpp#L18), [`:109-180`](../../../libotoworm/src/note_loader_sm.cpp#L109)).
- `.ssc` handles multiple `#NOTEDATA` blocks, common song metadata, global and chart-local BPMS/STOPS/WARPS/SCROLLS/SPEEDS, and chart fields such as credit, meter, difficulty, style, and step type ([`../libotoworm/src/note_loader_sm.cpp:414-579`](../../../libotoworm/src/note_loader_sm.cpp#L414)). Speed transitions are converted to time-duration/value records; warp and scroll data are also changed from beat domain to time domain before chart insertion ([`../libotoworm/src/note_loader_sm.cpp:320-388`](../../../libotoworm/src/note_loader_sm.cpp#L320), [`:565-579`](../../../libotoworm/src/note_loader_sm.cpp#L565)).
- The loader's own header comment states delays, speeds, and keysounds are missing; in practice SSC does parse `SPEEDS`, but neither SM path parses `DELAYS`, and the note records do not assign sound resources ([`../libotoworm/src/note_loader_sm.cpp:14`](../../../libotoworm/src/note_loader_sm.cpp#L14), [`:499-513`](../../../libotoworm/src/note_loader_sm.cpp#L499)). SM does not parse native `WARPS` or `SCROLLS`/`SPEEDS` directives in its loader path; SSC does. No source text or unknown field bag is retained. String decoding is a validity/fallback heuristic for selected common fields, not byte-preserving encoding provenance ([`../libotoworm/src/note_loader_sm.cpp:228-318`](../../../libotoworm/src/note_loader_sm.cpp#L228)).

### osu!mania `.osu`

- The reader accepts osu file versions 10+, requires `Mode: 3`, and reads only General, Metadata, Difficulty, Events, TimingPoints, and HitObjects sections ([`../libotoworm/src/note_loader_om.cpp:50-83`](../../../libotoworm/src/note_loader_om.cpp#L50), [`:824-907`](../../../libotoworm/src/note_loader_om.cpp#L824)). It copies title/artist (preferring Unicode variants), difficulty version and creator, key count, HP, OD, audio filename/preview time, and special style; other metadata such as tags, AR, bookmarks, and IDs is not mapped ([`../libotoworm/src/note_loader_om.cpp:395-513`](../../../libotoworm/src/note_loader_om.cpp#L395)).
- Hit objects are placed from x into a lane and timestamped in seconds. Mania holds retain an end time; normal notes and sliders are also read, with sliders converted to duration holds. The derived measure grid and beat mapping are generated from timing points; notes are then assigned into those measures ([`../libotoworm/src/note_loader_om.cpp:725-811`](../../../libotoworm/src/note_loader_om.cpp#L725), [`:180-300`](../../../libotoworm/src/note_loader_om.cpp#L180), [`:304-351`](../../../libotoworm/src/note_loader_om.cpp#L304)).
- Uninherited timing points generate BPM; inherited points generate scroll multipliers. The reader parses sample-set/custom fields but has no modeled kiai/unknown timing-effect bits ([`../libotoworm/src/note_loader_om.cpp:554-598`](../../../libotoworm/src/note_loader_om.cpp#L554), [`:813-822`](../../../libotoworm/src/note_loader_om.cpp#L813)). Sample filenames are synthesized from hit-sound/sample-set data; hitsounds can create BGM events, background events are mapped, and other event lines are kept in `OsumaniaChartTransient::osb_sprites` ([`../libotoworm/src/note_loader_om.cpp:515-551`](../../../libotoworm/src/note_loader_om.cpp#L515), [`:608-722`](../../../libotoworm/src/note_loader_om.cpp#L608), [`:888-890`](../../../libotoworm/src/note_loader_om.cpp#L888)). The bridge discards the filename map, BGM, background, event text and HP/OD values.

## Cross-format loss and precision notes

- **Timing domain:** the library loaders commonly retain both beat-domain parser inputs and normalized time-domain timing/note outputs only transiently. Wormedit converts the surviving bridge into seconds-keyed maps, losing rational local position, exact source pulse/fraction, source ordering, original units, authored measure-length provenance, and chart beat-zero/audio offset (`diff.offset` is never copied). The bridge does not copy SSC/OSU scroll data, though it copies the loader's `interpolated_speed_multipliers` when available.
- **Resources:** `ChartTransient` has a sound ID-to-path map, autoplay sound events, BMP tables/events, and BMSON slice data; `ChartGroup` has music, preview, background, title, artist, subtitle and genre. Wormedit copies just title/artist. Numeric note `wav` values therefore become unresolved IDs with no resource catalog or source lane. Unused WAV/BMP/sample definitions are already omitted by some loaders (BMS explicitly copies only used WAVs), so replacement codecs must preserve definitions before placement/use filtering.
- **Kinds and lanes:** libotoworm's `NoteData` contains start/end, head/tail sounds and a note-kind byte ([`../libotoworm/include/track_note.h:9-29`](../../../libotoworm/include/track_note.h#L9)); the current bridge maps every event to the same legacy `Note` record. Loader lane remapping (BMS/PMS/BMSON and osu x-to-column) is not accompanied by source channel identity or a recoverable format map.
- **Encoding and source fidelity:** the bridge carries no original bytes, encoding decision, comments, unknown field order, raw BMS command spelling, or loader provenance. The legacy `Chart` is not an editing-safe round-trip document, and wormedit currently has no writer. See the source encoding/provenance fields already sketched in [`include/wormedit/core/document.h:91-114`](../../include/wormedit/core/document.h#L91) and [`:510-520`](../../include/wormedit/core/document.h#L510).

## Wormedit-owned component assignment

These are ownership assignments for replacement work, not claims that the listed behavior is implemented. They follow the layered architecture and stage gates in [`docs/chart-editor-plan.md:43-76`](../chart-editor-plan.md#L43) and [`:708-726`](../chart-editor-plan.md#L708).

| Audited capability / loss | Wormedit owner | Required retained semantics |
|---|---|---|
| Bytes, encoding, comments, unknown fields, source spelling/order | Per-format byte-preserving codec plus shared text-decoding/provenance utility | Keep original bytes/encoding state for unchanged round-trip; normalized UTF-8 values; ordered known and unknown metadata/commands |
| BMS command syntax and conditional program | BMS codec + core BMS control-tree evaluator | Preserve original tree and raw statements, all delimiters and branch membership; make active branch selection explicit and deterministic without deleting alternatives |
| BMS/BME/BML/PMS channel decoding | BMS codec + data-defined lane-layout profiles | Preserve exact channel family/ID and custom layouts; map visible/LN/invisible/mine/scratch/autoplay/pedal without silently dropping ambiguous lanes |
| BMSON/SM/SSC/osu note kind, lane and measure placement | Format codec into `chart_document_t` | Rational measure-local positions, authored measure lengths and lane layout; typed tap/hold/roll/fake/mine/invisible/lift; preserve source-specific provenance and note sound reference |
| BPM, offset, stops, delays, warps, scroll and speed | Shared exact timing model/evaluator, with per-format adapters | Preserve authored beat positions, units, ordering and provenance; normalize legacy warp encodings canonically but retain original encoding; never replace the editable document with time-keyed maps |
| BGM events and repeated source tracks | Format codec + chart BGM-source-lane/event model | Ordered independent lanes and structural empty slots, source IDs and event positions; keep BGM separate from playable notes |
| WAV/BMP/sample/music/background resources | Song resource-catalog importer and per-format resource adapters | Keep used and unused declarations, role, original target identifier/path, missing-file state, and placed events separately; resolve paths safely and preserve stable identity |
| BMSON sound-channel slicing and mixed events | BMSON codec + shared audio-asset/clip/sound-channel model | Keep source asset and exact source-frame clip boundaries, restart/continuation flags and pulse positions; represent same-pulse polyphony/layers without rendering intermediate files |
| BGA, osu event/storyboard text and visual assets | Format codec into visual-resource/BGA model; storyboard codec later | Preserve event positions, layer/kind, references and unrecognized text; keep image/video/storyboard assets apart from events |
| Metadata, difficulty grouping and source chart choice | Song/chart metadata adapters and import selection policy | Import all difficulties where format is a set; retain scoped values, source order, ratings, IDs, tags and unsupported-but-round-trippable values |
| Export and information-loss reporting | Wormedit conversion pipeline and paired target writers | Explicit target profile, quantization/branch/warp/encoding policy, diagnostics and semantic re-import fixtures; no import-only format advertised as supported |

The current core aggregate already has draft homes for many of these responsibilities: chart-local rational measures/notes and typed timing events, ordered BGM lanes, BGA events, sound channels, and BMS control trees in [`include/wormedit/core/document.h:252-353`](../../include/wormedit/core/document.h#L252), [`:399-480`](../../include/wormedit/core/document.h#L399), and [`:483-547`](../../include/wormedit/core/document.h#L483); shared resources and audio clips in [`:407-465`](../../include/wormedit/core/document.h#L407). The audit's implementation warning is that `src/common/chart.cpp` currently bypasses those structures and is only a lossy import scaffold.
