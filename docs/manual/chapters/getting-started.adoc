[#getting-started]
= Getting started

== Installing

* *Windows:* unzip `wormedit-<version>-windows-x64.zip` anywhere and run `wormedit.exe`.
  Wormedit needs a GPU with Direct3D 12 or Vulkan.
* *Linux:* make `wormedit-<version>-x86_64.AppImage` executable (`chmod +x`) and run it. It
  needs glibc 2.35 or newer, an X11 or Wayland session and a working Vulkan driver.
* *macOS:* build `Wormedit.app` with `scripts/macos-package.sh` from the source checkout. The app
  is not signed: open it the first time with right-click *Open*.

Packages include this manual (*Help → User manual*), the Lua API reference and the exercise
files used in these chapters unless the manual was disabled when building the package.

== The start screen

With no project open, Wormedit offers two buttons: *New project* and *Open chart or project…*.
Recently opened files are listed under them.

[#new-project]
== Creating a project

Click *New project*, choose *File › New project*, or press kbd:[Ctrl+N]. The wizard asks one
question: the *chart layout*. Choose a game format, key count and layout variant, then click
*Create project*; kbd:[Escape] cancels. The lane preview shows the selected layout.
The new chart opens in Compose. Select *Draw* (kbd:[Alt+2]) to place notes with the mouse or
lane keys; kbd:[Space] plays the chart. Double-click a sound in the Sounds dock to arm it.
Without song audio, the canvas includes empty measures beyond the authored chart. Drawing there
creates the needed measures with the notes; cancelling a stroke leaves the chart unchanged.

To start with song audio, drop an MP3 or Ogg onto the start screen before choosing the layout.

.Creating a project (captured at {shot-new-project-wizard-revision})
image::new-project-wizard.png[The Create a new project dialog with its Chart layout list]

The layout decides the lanes, the default lane keys and which output formats the project starts
with:

* *1K–18K* are osu!mania layouts. 3K–8K and 10K also start with StepMania `.sm` and `.ssc`
outputs, because StepMania has a matching game type.
* *BMS 5K*, *BME 7K* and the *DP* (double play) variants are BMS layouts. Scratch can sit outside
or inside each stage; _free zone_ and _foot pedal_ variants add those lanes.
* *PMS* layouts are pop'n music (9 or 5 buttons, or BME-style channel numbering).
* *Pump*, *Solo* are StepMania-only layouts.
* *BMSON generic 24K / 48K* are keyboard-style BMSON layouts.

The <<layout-reference,layout reference>> lists every layout with its lanes, lane keys and
outputs. Double-play and the wider osu!mania layouts interleave the number row with the row
below it (for BME DP7: kbd:[1] kbd:[Q] kbd:[2] kbd:[W] … on the left, kbd:[Y] kbd:[7] kbd:[U]
kbd:[8] … on the right). A few wide layouts have no default lane keys yet; bind them in
*Options → Input & shortcuts → Lane keys…*, or place their notes with the mouse.

You can add more charts to the project later from the *Project* tab (kbd:[F1]): *New chart*
(kbd:[Ctrl+Shift+N]), *Import chart…* to bring in difficulties from another file, *Duplicate* and
*Delete*.

=== Changing the layout later

In Compose, the inspector's *Lane profile* section switches the chart between layouts with the same
number of lanes, for example BME 7K with the scratch outside or inside. The *Lane layout segment*
section changes the layout from the measure at the cursor onward, for charts that change key count
partway through.

[#opening]
== Opening charts and projects

*Open chart or project…* opens:

* Wormedit projects (`.wormedit`);
* BMS family charts (`.bms`, `.bme`, `.bml`, `.pms`) and BMSON (`.bmson`);
* StepMania (`.sm`, `.ssc`) and osu!mania (`.osu`) charts.

You can also drop any of these files onto the window. A BMS file with non-ASCII text and no UTF-8
marker asks which text encoding it uses (Shift-JIS is the usual answer for older Japanese charts).

An opened chart becomes a new, unsaved project that keeps reading its sounds from the chart's
folder. Save it with kbd:[Ctrl+S] to get a `.wormedit` project; exporting needs a saved project
(see <<walkthrough-bms>>).

Starting Wormedit with a chart path uses the same importer as *Open chart or project…*.

Choose *File → Open project folder* to open the project's directory in Finder or your system
file manager. Imported charts use their source folder until you save the project elsewhere.
A new project without a folder must be saved first. You can also find *Open project folder*
in the command menu.

=== Autosave and recovery

Wormedit keeps a periodic native backup and a checksummed edit journal, including for
untitled projects and imported charts. Commands, Undo and Redo are journaled. The next
edit waits for the previous record's worker flush, so the current edit may still be in
flight if the process stops. A full backup clears only the journal records it covers.

On reopening, use the recovery banner to inspect a validated snapshot, recover it into
the session, or save it as a new project. Each candidate shows only the actions that are
safe for it; candidates without one are listed on a single line for context. A damaged
final record leaves earlier valid edits recoverable. Recovery does not overwrite the primary project automatically.
Storage problems retain earlier artifacts and report a warning.

=== Per-difficulty metadata

On *Metadata* (kbd:[F2]), choose a difficulty and expand *Song field overrides*
inside its *Difficulty* section. A checked *Inherit* box shows the shared/source
value in grey. Uncheck it to enter a local export value. An empty local value is
kept explicitly; checking *Inherit* again restores inheritance. *Apply fields*
commits the group together, and one Undo restores the previous settings.

Music and preview-file values refer to audio already imported into the project.
Preview audio is a separate file; osu! preview time and StepMania sample timing
remain in their format-specific fields. Export reports unsupported fields or
conflicting song values in a multi-difficulty output group.

[#importing-assets]
== Importing sounds, images and song audio

=== Sounds (keysounds)

Drop audio files (WAV, Ogg, MP3 or FLAC) onto the *Sounds* list in Compose or Audio Slices, or
click the *+* button at the top of the Sounds dock. Wormedit shows a *Review sound import* dialog before anything changes:

* It suggests *sound groups* for the new files. Edit the group names, move sounds between
groups, add one with *Create new group*, or choose *Leave all ungrouped*.
* *Confirm import* adds everything in one step that a single Undo reverses.

.Review a staged sound before importing it (captured at {shot-sound-import-review-revision})
image::sound-import-review.png[Review sound import dialog with a staged keysound and Cancel and Confirm import buttons]

Sounds can be grouped later too: select them in the Sounds dock and click *Group…*. Its *Keep IDs
together* option keeps the group's BMS `#WAV` numbers next to each other.

For BMS charts you can also put sounds into exact `#WAV` slots; see <<bms-slots>>.

=== Compose dock

The narrow strip at the right of Compose opens Inspector, Sounds, Images, Measures, Layers,
Markers and Mixer. Click a panel button to show it alone; click the sole active panel again to hide it.
Hold kbd:[Shift] while clicking to add or remove a second panel. Adding a third replaces the second
pane. Each pane scrolls independently. Drag buttons along the strip to reorder them and the
visible panes. The *Side-by-side panels* button below the panel buttons switches between two
full-height columns and a vertical stack. Columns temporarily stack when the window is too narrow.
The right-hand strip is the only set of panel buttons. Drag the dock's left edge to change its width, or the divider between panes to
change their split. The layout is saved in application preferences and restored across projects
and restarts. Markers provides the same search and navigation as the bookmark chooser.

The *Mixer* sets playback levels by category: *Music* (the song audio), *BGM* (BGM lane keysounds
and stems), *Keysounds* (playable notes) and *Hitsounds* (osu! hitsounds), under a *Master* level
that also covers metronome clicks. Levels are in decibels: the top of each slider is 0 dB (the
authored level), each step lowers it by 0.6 dB, and the bottom is silence. *M* mutes a category; *S* solos it, and soloing several keeps
all of them audible. Changes apply to sounds that are already playing. The mix lasts for the
session and only affects listening: exports and the saved chart keep the authored mix. *Reset*
restores every level and clears mute and solo.

=== BGA images

Drop images onto the *Images* (BGA) list in Compose (show it from the right dock strip). Select an
image or video and click *Find uses* to see its BGA events
across the project's charts, including references through another resource sharing its asset.
Click a result to open that chart, move the cursor and select the exact event. The list shows
up to 1,024 uses, ordered by chart, position and BGA lane; it also includes missing resources.

=== Song audio

The song's main audio is set on the *Metadata* tab (kbd:[F2]): drop the file onto its audio field,
expand *Audio and export*, then click *Use as song audio*. Saving copies linked audio outside the
project directory into *assets/* and relinks it; a failed copy keeps the original link and reports
the file.

TIP: With no project open, dropping an MP3 or Ogg file onto the window offers to start a new
project from it: the same wizard opens, titled *Import audio as a new project?*, and the file
becomes the song audio.
