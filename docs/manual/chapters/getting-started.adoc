= Getting started

== The start screen

With no project open, Wormedit offers two buttons: *New project* and *Open chart or project…*.
Recently opened files are listed under them.

[#new-project]
== Creating a project

Click *New project*, choose *File › New project*, or press kbd:[Ctrl+N]. The wizard asks one
question: the *chart layout*. Pick it and click *Create project*; kbd:[Escape] cancels.

.Creating a project (captured at {shot-new-project-wizard-revision})
image::new-project-wizard.png[The Create a new project dialog with its Chart layout list]

The layout decides the lanes, the default lane keys and which output formats the project starts
with:

* *1K–18K* are osu!mania layouts. 3K–8K and 10K also start with StepMania `.sm` and `.ssc`
outputs, because StepMania has a matching game type.
* *BMS 5K*, *BME 7K* and the *DP* (double play) variants are BMS layouts. Scratch can sit outside
or inside each stage; _free zone_ and _foot pedal_ variants add those lanes.
* *PMS* layouts are pop'n music (9 or 5 buttons, or BME-style channel numbering).
* *Pump*, *Solo* are StepMania-only layouts.
* *BMSON generic 24K / 48K* are keyboard-style BMSON layouts.

The <<layout-reference,layout reference>> lists every layout with its lanes, lane keys and
outputs. Double-play and the wider osu!mania layouts interleave the number row with the row
below it (for BME DP7: kbd:[1] kbd:[Q] kbd:[2] kbd:[W] … on the left, kbd:[Y] kbd:[7] kbd:[U]
kbd:[8] … on the right). A few wide layouts have no default lane keys yet; bind them in
*Options → Input & shortcuts → Lane keys…*, or place their notes with the mouse.

You can add more charts to the project later from the *Project* tab (kbd:[F1]): *New chart*
(kbd:[Ctrl+Shift+N]), *Import chart…* to bring in difficulties from another file, *Duplicate* and
*Delete*.

=== Changing the layout later

In Compose, the inspector's *Lane profile* section switches the chart between layouts with the same
number of lanes, for example BME 7K with the scratch outside or inside. The *Lane layout segment*
section changes the layout from the measure at the cursor onward, for charts that change key count
partway through.

[#opening]
== Opening charts and projects

*Open chart or project…* opens:

* Wormedit projects (`.wormedit`);
* BMS family charts (`.bms`, `.bme`, `.bml`, `.pms`) and BMSON (`.bmson`);
* StepMania (`.sm`, `.ssc`) and osu!mania (`.osu`) charts.

You can also drop any of these files onto the window. A BMS file with non-ASCII text and no UTF-8
marker asks which text encoding it uses (Shift-JIS is the usual answer for older Japanese charts).

An opened chart becomes a new, unsaved project that keeps reading its sounds from the chart's
folder. Save it with kbd:[Ctrl+S] to get a `.wormedit` project; exporting needs a saved project
(see <<walkthrough-bms>>).

NOTE: Starting Wormedit from a command line only opens a `.wormedit` project. Open other chart
formats from inside the editor.

=== Autosave and recovery

Wormedit keeps a periodic native backup and a checksummed edit journal, including for
untitled projects and imported charts. Commands, Undo and Redo are journaled. The next
edit waits for the previous record's worker flush, so the current edit may still be in
flight if the process stops. A full backup clears only the journal records it covers.

On reopening, use the recovery banner to inspect a validated snapshot, recover it into
the session, or save it as a new project. A damaged final record leaves earlier valid
edits recoverable. Recovery does not overwrite the primary project automatically.
Storage problems retain earlier artifacts and report a warning.

[#importing-assets]
== Importing sounds, images and song audio

=== Sounds (keysounds)

Drop audio files (WAV, Ogg, MP3 or FLAC) onto the *Sounds* list in Compose or Audio Slices, or
click the *+* button at the top of the Sounds dock. Wormedit shows a *Review sound import* dialog before anything changes:

* It suggests *sound groups* for the new files. Edit the group names, move sounds between
groups, add one with *Create new group*, or choose *Leave all ungrouped*.
* *Confirm import* adds everything in one step that a single Undo reverses.

Sounds can be grouped later too: select them in the Sounds dock and click *Group…*. Its *Keep IDs
together* option keeps the group's BMS `#WAV` numbers next to each other.

For BMS charts you can also put sounds into exact `#WAV` slots; see <<bms-slots>>.

=== BGA images

Drop images onto the *BGA* list in Compose (show it with the BGA list button at the right
end of the toolbar).

=== Song audio

The song's main audio is set on the *Metadata* tab (kbd:[F2]): drop the file onto its audio field,
expand *Audio and export*, then click *Use as song audio*. Saving copies linked audio outside the
project directory into *assets/* and relinks it; a failed copy keeps the original link and reports
the file.

TIP: With no project open, dropping an MP3 or Ogg file onto the window offers to start a new
project from it: the same wizard opens, titled *Import audio as a new project?*, and the file
becomes the song audio.
