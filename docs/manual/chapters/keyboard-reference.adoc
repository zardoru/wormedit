= Keyboard reference

== Commands

Every command below can be rebound in *Options* (kbd:[Ctrl+,]); the tables list the defaults.
Commands marked _unbound_ have no default key and can be run from the command menu
(kbd:[Ctrl+Shift+P]) or given one.

== Lane keys per layout

Open *Lane Keys…* from the command menu, or *Options → Input & shortcuts → Lane keys…*.
Click a lane and press a letter or digit, or click its key on the keyboard map. Bindings use
physical key positions, so changing the keyboard language does not move them. Backspace unbinds
the selected lane; Escape during capture keeps its previous key.

Choose *Wormedit default*, the available *iBMSC interleaved (DP)* preset, or customize individual
lanes. Duplicate keys are flagged and block Apply. Space, Tab, arrows and editing keys are reserved.
*Apply* saves the current layout's keys to your program preferences; every chart with that layout
uses them. It does not edit the project or add an Undo step. Cancel discards the draft.

*Reset to preset* stages removal of the personal override. Apply then restores the chart's stored
bindings, which are also the fallback for a layout you have never customized.

== Keys that are not commands

These keys are part of Compose itself. Lane keys can be customized separately; the other keys
in this table cannot be rebound. On macOS, use the Control key for kbd:[Ctrl+Space] and
kbd:[Ctrl+G], rather than Command.

[cols="2,3",options="header"]
|===
|Keys |Action

|lane keys
|Place or remove the armed note at the cursor (Draw tool), or move the selection to that lane.
See the <<layout-reference,layout reference>> for the defaults, or open *Lane Keys…* from the
command menu or *Options → Input & shortcuts* to customize the current layout.

|kbd:[Shift] + lane key
|Move the first selected note to that lane and deselect it.

|lane key held + cursor movement
|Draw a hold.

|kbd:[Up] / kbd:[Down]
|Move the cursor one snap.

|kbd:[PgUp] / kbd:[PgDn] (RePág / AvPág; macOS: kbd:[Option+Up] / kbd:[Option+Down])
|Skip one measure.

|kbd:[Tab] held + arrows / kbd:[PgUp] / kbd:[PgDn]
|Accelerate: one measure (arrows) or two (page keys) per press.

|kbd:[Alt]-drag a note (Select tool)
|Lengthen or shorten it; with a selection, every selected note.

|kbd:[Shift] + cursor movement
|Select the range the cursor passes over.

|kbd:[Ctrl+Space]
|Start or finish a latched range. Space toggles playback while its tail follows; Escape stops playback first, then cancels the range when stopped.

|kbd:[Ctrl+G]
|Go to measure.

|kbd:[Enter] / kbd:[Escape] during a paste
|Place or cancel the paste.

|kbd:[Alt] + wheel
|Step the cursor to the next snap.

|kbd:[Ctrl] + wheel
|Zoom around the pointer.
|===
