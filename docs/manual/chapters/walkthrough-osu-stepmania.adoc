[#walkthrough-osu-stepmania]
= Walkthrough: an osu!mania and StepMania chart

One Wormedit project can export the same chart to osu!mania and to StepMania. This chapter makes a
7K chart from a song file and exports `.osu` and `.ssc` files from it. Duplicate the StepMania
target when you also want an independent `.sm` export.

== 1. Start from the song

With no project open, drop the song's MP3 or Ogg file onto the window. Wormedit asks *Import audio
as a new project?* with the layout list: choose *7K* (or *4K*, …) and click *Create project*. The
file becomes the song audio. Keep it as song audio; you do not need to slice the MP3 or import
separate samples to use osu!'s built-in hitsounds in step 4.

You can also create the project with kbd:[Ctrl+N] and drop the song onto the audio field of the
*Metadata* tab (kbd:[F2]) afterwards. Expand *Audio and export*, then click *Use as song audio*.

Layouts 3K to 8K and 10K start with two export targets, *osu!mania* and *StepMania*, both including
the new chart. Other key counts start with osu!mania only (see the
<<layout-reference,layout reference>>).

== 2. Find the tempo

* Set the starting BPM by double-clicking the BPM marker at the bottom of the BPM lane and typing
the value.
* If you do not know it, run *Tap Timing* from the command menu (kbd:[Ctrl+Shift+P]) and press
kbd:[T] on the beat while the song plays.
* In Timing focus (kbd:[F3]), kbd:[Ctrl]-drag a beat line onto the waveform to fit the tempo to
the audio; the BPM snap buttons in the toolbar set the step (kbd:[Ctrl] + wheel while dragging
changes it).

In Timing focus (kbd:[F3]), lock the timing with kbd:[Ctrl+Shift+T] once it is right, so later
edits cannot move it. Press kbd:[F4] to return to Compose before charting; the lock stays active.

== 3. Chart

For osu!mania and StepMania you usually do not need sounds on notes: with nothing armed, lane keys
and the Draw tool place plain notes.

. kbd:[Alt+2] for the Draw tool.
. kbd:[Left]/kbd:[Right] to pick the snap; the status bar shows it.
. Walk with kbd:[Up]/kbd:[Down] and press lane keys kbd:[1] to kbd:[7] to place notes. Hold a lane
key while walking for a hold note.
. kbd:[Space] to listen from the cursor; kbd:[Ctrl+F11]/kbd:[Ctrl+F12] to slow down or speed up
playback while you check a dense part.
. Fix with the mouse: press kbd:[Alt+1] and drag a note to move it; press kbd:[Alt+2] for Draw,
then right-drag to erase. kbd:[Alt]-drag on an empty lane draws a hold.

StepMania mines, lifts, fakes and rolls are on kbd:[Alt+4] to kbd:[Alt+8] when the chart's formats
support them.

== 4. Add osu! hitsounds

The 7K project has both osu!mania and StepMania export targets, so it starts as a native chart.
Its osu! hitsound controls are initially hidden. You can enable them here without importing an
existing `.osu` file.

. Return to Compose with kbd:[F4]. If the hitsound tiles are hidden, open the command menu
  (kbd:[Ctrl+Shift+P]), search for *Show hitsound palette* and run it. The tiles appear below the
  note-kind palette.
. Press kbd:[Alt+1] for Select and click one of the taps you placed in step 3.
. Click the clapping-hands tile (*Clap*, kbd:[R]). Its checkbox turns on for the selected note.
  The whistle (*Whistle*, kbd:[W]) and cymbal (*Finish*, kbd:[E]) tiles work the same way; you can
  combine additions on one note.
. Right-click the music-note selector (*Normal sample set*) and choose *Soft*. Right-click the
  layers selector (*Addition sample set*) and choose *Drum*. The normal hit now uses Soft and the
  clap uses Drum. Hover the note to check its sample sets and additions.
. Press kbd:[Space] to listen. If hitsounds are muted, enable *Playback → Play Hitsounds on
  Playback*. Wormedit supplies bundled samples, so this check needs only your song file.

To set defaults for new notes instead, clear the selection with kbd:[Escape] when no gesture is
active, choose the hitsound tiles, then switch to Draw (kbd:[Alt+2]) and place another tap or
hold. Editing selected notes does not change those defaults. To brush settings across existing
notes, follow <<painting-sounds,Painting sounds on existing notes>>.

The note settings are saved in the `.wormedit` project and written to its osu!mania export.
See <<osu-hitsounds,osu! hitsounds>> for Auto sample sets, shortcuts and audition settings.

== 5. More difficulties

On the *Project* tab (kbd:[F1]), open the chart's *⋯* menu and choose *Duplicate* to start another
difficulty; it keeps the chart's timing. The *New chart* button (kbd:[Ctrl+Shift+N]) adds a
chart with 120 BPM and one measure, carrying over the layout and audio offset. Add each chart to the
export targets that should export it. Click the chart's *Exports* cell to check or uncheck targets,
or use the add button and removable chart chips on a target card. A target editor shows the same
complete membership. Charts whose lane layout cannot be represented by that format stay visible but disabled
with the reason; an existing incompatible membership remains visible until you remove it.

== Add a background image

In *Compose*, open the *Images* dock from the right-hand panel strip. Click its *+* button
(or drop an image into the dock), then double-click the imported image to arm it. If the lane
is hidden, choose *BGA* under *Show BGA lanes*. Place the image at the very first row of the
chart. Importing alone adds it to the catalog; placing it gives the chart its background.

Use one still image at the first row for a background shared by osu!mania, SM and SSC exports.
If a StepMania target includes several charts, place the same image in each chart.
StepMania export reports conflicting backgrounds or unsupported animated BGA instead of
silently dropping them. Select the placed event to replace or delete it through the normal
BGA controls. Imported StepMania `BACKGROUND` images appear in this same lane.

Save the project, then export the target as described below. The export copies the image
into its *assets/* directory and writes the matching relative reference in the chart.

== 6. Save and export

. kbd:[Ctrl+S] saves the `.wormedit` project; exporting needs a saved project.
. On the *Project* tab, under *Exports*, open each target's *⋯* menu and choose *Edit*. Set its
*Destination*, relative to the project:
for example `osu/song.osu` and `ssc`, or a folder when a group exports several osu!mania
charts.
. If the project has no targets, choose a layout-derived suggestion in the empty *Exports* section.
  This opens the normal target editor; nothing is added until you click *Save*.
. Set *Existing files* to *Ask*, *Replace*, or *Keep*. *Ask* publishes immediately when every
  planned filename is free, and shows one confirmation listing conflicts before replacing any file.
. In each StepMania target's editor, choose its *File profile* (SM or SSC), target implementation
  (StepMania 5.1 or Etterna 0.75.1) and *Timing syntax*. Preview and Export use that target's saved
  choices. Duplicate the target to keep separate SM and SSC policies.
. Click a target card's *Export* button to use its saved policy. Its *⋯* menu can export once with
*Replace* or *Keep* without changing that saved choice. *Export all* prepares every target before
publishing the first one. *File → Export…* opens the same target and policy choices from any tab.
The target's *⋯* menu also contains *Preview*, *Duplicate* and *Delete…*. *Preview*
  lists the files, asset copies and warnings that the same export plan would publish; it does not
  write files. It also reports the plan's conversion and publication refusals.

Save the project before exporting. Saving copies linked assets outside the project directory into
*assets/* and relinks them; a failed copy keeps the original link and reports the file. osu!mania and
StepMania exports copy the song audio next to the chart file. A project with more than one music
resource cannot be exported to them, even if the resources refer to the same file; Wormedit reports
the refusal without publishing partial files.

== Try it without an external song

First open the bundled `fixtures/comparison/comparison.wormedit` beside this HTML manual
(`docs/manual/fixtures/comparison/comparison.wormedit` in a source checkout). Its Baseline and
Variation difficulties give you a populated 4-lane example: try the <<comparing,comparison exercise>>,
then return to Project to inspect their notes and ratings. Leave this reference unchanged.

Now create a new *4 keys* osu!mania project. Its matching StepMania outputs let you practice the
editing/export flow with no downloaded assets. Save the project to a disposable directory.

. Leave the sound source unarmed, select Draw, and place four taps in different lanes one snap apart.
. Hold one lane key while advancing four snaps; release it and check the hold's tail.
. Follow step 4 to show the hitsound palette. Select one tap and give it a Clap with a Drum
  addition sample set. Hover it to check the settings, then play it back using the bundled
  hitsounds. The other taps should keep their original settings.
. Duplicate the difficulty on Project. Remove two taps from the duplicate and give it a different
  name/rating. The original difficulty should retain all four taps.
. Include both difficulties in the osu!mania and StepMania targets. Set separate destination
  folders and run Preview on each; inspect its files and warnings before Export.
. In <<comparing,Compare / Validate>>, check that the tap removals appear as differences.

This is an editing and export-planning exercise; a chart without song audio is not a finished
playable song. For the audio workflow, repeat it using your own licensed song as in step 1.
