[#walkthrough-osu-stepmania]
= Walkthrough: an osu!mania and StepMania chart

One Wormedit project can export the same chart to osu!mania and to StepMania. This chapter makes a
7K chart from a song file and exports `.osu`, `.sm` and `.ssc` files from it.

== 1. Start from the song

With no project open, drop the song's MP3 or Ogg file onto the window. Wormedit asks *Import audio
as a new project?* with the layout list: choose *7K* (or *4K*, …) and click *Create project*. The
file becomes the song audio.

You can also create the project with kbd:[Ctrl+N] and drop the song onto the audio field of the
*Metadata* tab (kbd:[F2]) afterwards. Expand *Audio and export*, then click *Use as song audio*.

Layouts 3K to 8K and 10K start with three export targets, *osu!mania*, *StepMania SM* and *StepMania
SSC*, all including the new chart. Other key counts start with osu!mania only (see the
<<layout-reference,layout reference>>).

== 2. Find the tempo

* Set the starting BPM by double-clicking the BPM marker at the bottom of the BPM lane and typing
the value.
* If you do not know it, run *Tap Timing* from the command menu (kbd:[Ctrl+Shift+P]) and press
kbd:[T] on the beat while the song plays.
* In Timing focus (kbd:[F3]), kbd:[Ctrl]-drag a beat line onto the waveform to fit the tempo to
the audio; the BPM snap buttons in the toolbar set the step (kbd:[Ctrl] + wheel while dragging
changes it).

In Timing focus (kbd:[F3]), lock the timing with kbd:[Ctrl+Shift+T] once it is right, so later
edits cannot move it. Press kbd:[F4] to return to Compose before charting; the lock stays active.

== 3. Chart

For osu!mania and StepMania you usually do not need sounds on notes: with nothing armed, lane keys
and the Draw tool place plain notes.

. kbd:[Alt+2] for the Draw tool.
. kbd:[Left]/kbd:[Right] to pick the snap; the status bar shows it.
. Walk with kbd:[Up]/kbd:[Down] and press lane keys kbd:[1] to kbd:[7] to place notes. Hold a lane
key while walking for a hold note.
. kbd:[Space] to listen from the cursor; kbd:[Ctrl+F11]/kbd:[Ctrl+F12] to slow down or speed up
playback while you check a dense part.
. Fix with the mouse: press kbd:[Alt+1] and drag a note to move it; press kbd:[Alt+2] for Draw,
then right-drag to erase. kbd:[Alt]-drag on an empty lane draws a hold.

StepMania mines, lifts, fakes and rolls are on kbd:[Alt+4] to kbd:[Alt+8] when the chart's formats
support them.

== 4. More difficulties

On the *Project* tab (kbd:[F1]), open the chart's *⋯* menu and choose *Duplicate* to start another
difficulty; it keeps the chart's timing. The *+* button (*New chart*, kbd:[Ctrl+Shift+N]) adds a
chart with 120 BPM and one measure, carrying over the layout and audio offset. Add each chart to the
export targets that should export it.

== 5. Save and export

. kbd:[Ctrl+S] saves the `.wormedit` project; exporting needs a saved project.
. On the *Project* tab, under *Exports*, open each target's *⋯* menu and choose *Edit*. Set its
*Destination*, relative to the project:
for example `osu/song.osu` and `sm/song.sm`, or a folder when a group exports several osu!mania
charts.
. For the StepMania groups, the *StepMania export policy* chooses the target (StepMania 5.1 or
  Etterna 0.75.1) and how timing is written (*Timing syntax*); Preview and Export use those
  choices. SM or SSC is inferred from the output path.
. Click a target card's *Export* button, or use *Export…* to choose a target and overwrite policy.
The target's *⋯* menu contains *Preview*, *Duplicate* and *Delete…*. *Preview*
  lists the files, asset copies and warnings that the same export plan would publish; it does not
  write files. It also reports the plan's conversion and publication refusals.

Save the project before exporting. Saving copies linked assets outside the project directory into
*assets/* and relinks them; a failed copy keeps the original link and reports the file. osu!mania and
StepMania exports copy the song audio next to the chart file. A project with more than one music
resource cannot be exported to them, even if the resources refer to the same file; Wormedit reports
the refusal without publishing partial files.
