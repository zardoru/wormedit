== About this manual

Wormedit is a chart editor for BMS, BMSON, osu!mania and StepMania. It is a _hybrid_ editor: the
mouse-driven drawing and keysounding of BMS editors such as iBMSC and BMSE, and the
keyboard-driven cursor, snaps and lane keys of the StepMania editor, work on the same canvas at
the same time. The fastest way to chart in Wormedit is to use both, and this manual teaches them
together.

This manual describes what the editor does today. Shortcut and layout tables are generated from
the editor's own code, and every screenshot is captured from the real application. Each figure
caption names the commit it was captured from; if the interface has changed since, the picture
may be out of date.

Open this book from *Help → User manual*, or *Help → About WormEdit → Open user manual*.
Packages include the HTML book and example projects unless the manual was explicitly disabled
when building the package. Examples are in `fixtures/` beside `index.html`; in a source
checkout they are under `docs/manual/fixtures/`.

Keys are written with Linux and Windows names. On macOS, kbd:[Ctrl] in the tables is
kbd:[Cmd]{nbsp}(⌘) and kbd:[Alt] is kbd:[Option].
