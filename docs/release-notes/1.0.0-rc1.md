# Wormedit 1.0.0-rc1 release notes

The first release candidate of Wormedit 1.0, a rhythm chart editor for BMS, BMSON,
StepMania and osu!mania. It is feature-complete for charting a song from audio to exported
files. Please try it on real charts and report what breaks before 1.0.0.

## Downloads and requirements

| Platform | Download | Requirements | Status |
| --- | --- | --- | --- |
| Windows | `wormedit-1.0.0-rc1-windows-x64.zip` | 64-bit Windows; a GPU with Direct3D 12 or Vulkan | Packaged and checked under Wine; please report results from real Windows machines |
| Linux | `wormedit-1.0.0-rc1-x86_64.AppImage` | x86_64, glibc 2.35 or newer (Ubuntu 22.04 era and later), X11 or Wayland, a working Vulkan driver | Packaged and checked |
| macOS | Build it yourself with `scripts/macos-package.sh` (see `docs/building.md`) | Apple Silicon or Intel, Xcode Command Line Tools, Homebrew | Verified by the maintainer on macOS 26.6.2 (Apple Silicon M5); Intel Macs untested; no download yet |

Unzip the Windows package anywhere and run `wormedit.exe`. Make the AppImage executable
(`chmod +x`) and run it. Both include the offline user manual (**Help → User manual**), the
Lua API reference, the manual's exercise files and the third-party license notices.

**macOS builds are not signed or notarized.** On first launch, right-click the app and choose
**Open**, or use **System Settings → Privacy & Security → Open Anyway**. A build made with
Homebrew's FFmpeg is for your own use only; it is not redistributable.

## What's in it

- **Hybrid charting:** BMS-editor mouse drawing and keysounding and StepMania-style keyboard
  cursor, snaps and lane keys on one canvas, with a command palette for everything else.
- **Formats:** BMS family (`.bms` `.bme` `.bml` `.pms`, including `#RANDOM`/`#IF`/`#SWITCH`
  branches and legacy encodings), BMSON, StepMania `.sm`/`.ssc` (StepMania 5.1 and Etterna
  targets) and osu!mania `.osu` (1K–18K, v14 and v128). Output groups export one project to
  several formats and report what a format cannot store.
- **Timing:** exact positions; BPM, stops, delays, warps, scroll velocity, StepMania speeds and
  kiai in lanes beside the notes; editable bar lines; tap tempo, waveform beat fitting, a
  metronome and SV recipes.
- **Audio:** streaming playback with waveforms, per-note audition, playback from 0.1× to 1×,
  nondestructive export cuts shared by every difficulty, preview-audio export, and BPM-grid
  slicing of long sounds into keysounds.
- **Lua scripting** (included in all packages): note and difficulty generators, `project.lua`
  includes and custom SV curves, with preview before Apply and one Undo step.
- **Checking and safety:** an in-editor player preview, external-player launch, atomic saves,
  autosave and crash recovery.

## Project files

A project is a folder: one `.wormedit` file plus its sounds, images and video as ordinary files
beside it, so you can manage assets with your usual tools. This is the 1.0 format.

- Projects from earlier Wormedit builds are upgraded when opened. This release writes project
  schema 25.
- A build refuses a project written by a newer version instead of silently dropping what it
  does not understand. Keep a copy if you go back to an older build.

## Lua API

The scripting API is version 1 and documented in the packaged Lua API reference. Scripts are
saved with the project and can be rerun without the original files.

## Changes since the last development snapshot

- BMS charts with branches can be exported to osu!mania, StepMania and BMSON: enable
  **Flatten BMS branches to the active outcome** on the output group. BMS scratch lanes become
  ordinary osu!mania columns.
- osu!mania and StepMania exports now copy every referenced keysound and image, not only the
  music.
- Bookmarks can be sorted and manually reordered; the order is saved with the project.
- The UI scale is capped so the layout always fits the window; Options shows the scale in use.
- Windows: projects in folders with non-ANSI names (for example `曲`) open from the command line
  and Explorer.

## Known limitations

- **Audio Slices tab:** unfinished. Its sound list, tags, waveform and slicer work, but expect
  its workflow and layout to change before 1.0.0.
- **Compare / Validate tab:** usable for side-by-side difficulty comparison and validation that
  jumps to the problem, but it received little attention in this release and is rough.
- **Storyboard tab:** disabled. osu! storyboards (`.osb`), the OSBX format and storyboard video
  export are planned, not shipped.
- **Formats not yet supported:** Quaver (`.qua`), StepMania rolls authoring and SSC
  `TICKCOUNTS`, and Standard MIDI import and export.
- **Sounds:** one sound per note. Layered multi-voice sounds and BMSON layered authoring are
  planned.
- **Interface language:** English only. Japanese, Chinese and Korean text in charts and file
  names displays correctly, but the interface is not translated.
- **Lane layouts:** Metadata's key-count selector lists **Custom** but it is disabled until a
  per-lane mapping editor exists. BMSON 48K charts have no per-stage focus for lane keys.
- **BMS repair:** malformed `#IF`/`#RANDOM`/`#SWITCH` blocks are preserved exactly on export,
  but Wormedit does not yet offer repair suggestions for them.
- **Diagnostics:** import warnings and export losses are listed in notifications, but cannot
  jump to the affected note yet.
- **Icon:** the application icon is a placeholder.

## Reporting problems

Open an issue at <https://github.com/zardoru/wormedit/issues>. Include your operating system,
GPU and driver version, the exact error text, and, if you can, the project or chart that shows
the problem. The manual's troubleshooting chapter lists the messages Wormedit reports and what
to check first.
