# Wormedit 1.0.0-rc3 release notes

The third release candidate of Wormedit 1.0, a rhythm chart editor for BMS, BMSON,
StepMania and osu!mania. It is a small update on rc2: Compose selection and navigation fixes,
steadier menus, and better osu!mania output for BMSON scratch lanes. Please keep trying it on
real charts and report what breaks before 1.0.0.

## Downloads and requirements

| Platform | Download | Requirements | Status |
| --- | --- | --- | --- |
| Windows | `wormedit-1.0.0-rc3-windows-x64.zip` | 64-bit Windows; a GPU with Direct3D 12 or Vulkan | Packaged and checked under Wine; please report results from real Windows machines |
| Linux | `wormedit-1.0.0-rc3-x86_64.AppImage` | x86_64, glibc 2.35 or newer (Ubuntu 22.04 era and later), X11 or Wayland, a working Vulkan driver | Packaged and checked |
| macOS | Build it yourself with `scripts/macos-package.sh` (see `docs/building.md`) | Apple Silicon or Intel, Xcode Command Line Tools, Homebrew | No download; build it from source. |

Unzip the Windows package anywhere and run `wormedit.exe`. Make the AppImage executable
(`chmod +x`) and run it. Both include the offline user manual (**Help → User manual**), the
Lua API reference, the manual's exercise files and the third-party license notices.

**macOS builds are not signed or notarized.** On first launch, right-click the app and choose
**Open**, or use **System Settings → Privacy & Security → Open Anyway**. A build made with
Homebrew's FFmpeg is for your own use only; it is not redistributable.

## Upgrading from rc2

Nothing to do. rc3 writes the same **project schema 28** as rc2, so projects open in both.

## Fixes

- **Compose:** notes can be selected while a semantic layer is soloed; the cursor can be moved
  with the keyboard during a mouse area selection; navigation keys released while the mouse
  holds a capture no longer stay pressed; objects can be copied together with a latched range
  selection.
- **Waveform:** detail requests work correctly after audio cuts.
- **Export:** BMSON scratch lanes are written in a form osu!mania accepts.
- **Menus:** open menus no longer flicker when a tooltip appears, and a click on a menu row no
  longer reaches the button underneath (for example, an export target's Preview row also
  exported the next target).
- **Build:** fixed undefined exports in the encoder-only LAME SDK build.

## Internal

Less coupling between application, input and chart-collection code, and less rebuilding while
developing. No change in behavior is intended.

## Known limitations

Unchanged from rc2:

- **Audio Slices tab:** unfinished; expect its workflow and layout to change before 1.0.0.
- **Compare / Validate tab:** usable, but rough.
- **Storyboard tab:** disabled. osu! storyboards (`.osb`), the OSBX format and storyboard video
  export are planned, not shipped.
- **Formats not yet supported:** Quaver (`.qua`), StepMania rolls authoring and SSC
  `TICKCOUNTS`, and Standard MIDI import and export.
- **Sounds:** one sound per note. Layered multi-voice sounds and BMSON layered authoring are
  planned.
- **Interface language:** English only. Japanese, Chinese and Korean text in charts and file
  names displays correctly, but the interface is not translated.
- **Lane layouts:** Metadata's key-count selector lists **Custom** but it is disabled until a
  per-lane mapping editor exists. BMSON 48K charts have no per-stage focus for lane keys.
- **BMS repair:** malformed `#IF`/`#RANDOM`/`#SWITCH` blocks are preserved exactly on export,
  but Wormedit does not yet offer repair suggestions for them.
- **Diagnostics:** import warnings and export losses are listed in notifications, but cannot
  jump to the affected note yet.
- **Icon:** the application icon is a placeholder.

## Reporting problems

Open an issue at <https://github.com/zardoru/wormedit/issues>. Include your operating system,
GPU and driver version, the exact error text, and, if you can, the project or chart that shows
the problem. The manual's troubleshooting chapter lists the messages Wormedit reports and what
to check first.
