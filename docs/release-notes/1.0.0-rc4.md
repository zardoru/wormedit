# Wormedit 1.0.0-rc4 release notes

The fourth release candidate of Wormedit 1.0, a rhythm chart editor for BMS, BMSON,
StepMania and osu!mania. It adds scrubbing and smoother scrolling while playing, a resizable
timing region in Compose, BGM columns in every format, a polish pass over popups, tooltips and
menus, and downloadable macOS builds. Please keep trying it on real charts and report what
breaks before 1.0.0.

## Downloads and requirements

| Platform | Download | Requirements | Status |
| --- | --- | --- | --- |
| Windows | `wormedit-1.0.0-rc4-windows-x64.zip` | 64-bit Windows; a GPU with Direct3D 12 or Vulkan | Built by CI; please report results from real Windows machines |
| Linux | `wormedit-1.0.0-rc4-x86_64.AppImage` | x86_64, glibc 2.35 or newer (Ubuntu 22.04 era and later), X11 or Wayland, a working Vulkan driver | Built by CI |
| macOS | `Wormedit-1.0.0-rc4-macos-arm64.zip` (Apple Silicon), `Wormedit-1.0.0-rc4-macos-x86_64.zip` (Intel) | macOS 26.0 or newer | Built by CI, **new in rc4**; not yet run on a Mac by the maintainer, so please report results |

Unzip the Windows package anywhere and run `wormedit.exe`. Make the AppImage executable
(`chmod +x`) and run it. The Windows and Linux packages include the offline user manual
(**Help → User manual**), the Lua API reference, the manual's exercise files and the
third-party license notices.

**macOS builds are ad-hoc signed, not notarized.** On first launch, right-click the app and
choose **Open**, or use **System Settings → Privacy & Security → Open Anyway**. Building from
source with `scripts/macos-package.sh` still works (see `docs/building.md`); a build made with
Homebrew's FFmpeg is for your own use only and is not redistributable.

## Upgrading from rc3

Nothing to do. rc4 writes the same **project schema 28** as rc3, so projects open in both.

## What's new

- **Scrub audio.** Scrolling with a touchpad plays the song like a needle on a record: the
  audio follows the scroll speed and direction, holds while your fingers rest on the pad, and
  resumes playback if you interrupted it.
- **Playback scrolling.** Stepping by row, measure and page is aware of export cuts, in both
  the parked cursor and the playing playhead; touchpad scrolling is smooth on macOS; the
  playhead moves continuously while playing; bookmarks inside a cut are hidden; and the source
  and Compose clock and coordinate readouts have tooltips.
- **Timing region handle.** A drag handle on the right edge of Compose's timing rows sets
  the region's width (double-click for automatic, Esc to cancel). When there is no room, lanes
  hide in order: anchor, kiai, warp, speed, delay, stop and BPM last.
- **BGM columns in every format.** The **+/-** control for BGM columns is no longer limited to
  BMS and osu!mania: native projects, StepMania, BMSON and others can grow and shrink them.
- **Next free BMS slot.** Commands and buttons find the next free WAV slot
  (`Ctrl/Cmd+Shift+F`, which selects it in the Sounds BMS slots list) or BMP slot
  (`Ctrl/Cmd+Alt+F`), wrapping past `ZZ`.
- **Idle frame loop.** Wormedit sleeps when nothing is changing instead of redrawing
  continuously, which lowers CPU and battery use.
- **Keep audio time on every timed object.** Timing edits now keep the audio time of
  unchanged BPM changes, stops, delays and warps as well as sound objects, and notes, BGM, SV,
  speeds, kiai, sample controls, BGA, timing anchors and SV recipe ranges follow the final
  timing. New bookmarks keep their place in the song, and the bookmark popup (now **Edit
  bookmark**) has a **Keep audio time** checkbox. The inline timing popup sizes itself to its
  rows and explains the option in a tooltip.
- **macOS downloads** for Apple Silicon and Intel (see above).

## Fixes and polish

- **Interface:** every popup now shares one menu-style surface (rounded, shadowed, with
  padding that matches menus); rename bookmark, note and section labels and Go to measure use
  one prompt with a hint line; tooltips wrap cleanly with even padding and borders; stem lanes
  and dock handles share one resize cursor; the text caret blinks on a steady cycle.
- **Waveform:** songs near 44.1 kHz (for example 44,099 Hz) no longer leave "Preparing song
  waveform" up forever. A resampler filter diverged for those rates and the waveform view
  silently rejected the whole analysis; the filter is now skipped in that narrow band, and the
  audio decoder never returns non-finite samples, which also kept a stray one from reaching
  playback at full scale.
- **Compose:** arrow glyphs are no longer clipped to a short note's rectangle (the head and
  stem were cut); hitsound icons, arrows and sound labels no longer shrink or slide while a note
  scrolls into view; beat lines of unmetered short measures (for example 5/16) no longer show
  standard-measure pulses when snap follows the measure.
- **osu!mania export:** red timing lines are written only where the BPM or meter changes.
- **Manual, BMSON export:** a new chapter on exporting BMSON charts to other formats. It
  treats BMSON as the format to author in and the players that cannot read it as legacy
  targets, with the sliced exports as copies for them; osu!mania and Quaver are described as
  separate use cases, not legacy players.
- **Windows:** fixes for the MSVC build, path handling (output-group paths reject backslashes
  on every platform) and portability of the tests.

## Internal

Faster builds (ccache, a faster linker and a header-weight ratchet), smaller test files, one
validation path for UI actions, per-domain request types in place of one large workspace action,
a refreshed complexity baseline, and tests that no longer write into tracked folders. No change in behavior is intended.

## Known limitations

Unchanged from rc3:

- **Audio Slices tab:** unfinished; expect its workflow and layout to change before 1.0.0.
- **Compare / Validate tab:** usable, but rough.
- **Storyboard tab:** disabled. osu! storyboards (`.osb`), the OSBX format and storyboard video
  export are planned, not shipped.
- **Formats not yet supported:** Quaver (`.qua`), StepMania rolls authoring and SSC
  `TICKCOUNTS`, and Standard MIDI import and export.
- **Sounds:** one sound per note. Layered multi-voice sounds and BMSON layered authoring are
  planned.
- **Interface language:** English only. Japanese, Chinese and Korean text in charts and file
  names displays correctly, but the interface is not translated.
- **Lane layouts:** Metadata's key-count selector lists **Custom** but it is disabled until a
  per-lane mapping editor exists. BMSON 48K charts have no per-stage focus for lane keys.
- **BMS repair:** malformed `#IF`/`#RANDOM`/`#SWITCH` blocks are preserved exactly on export,
  but Wormedit does not yet offer repair suggestions for them.
- **Diagnostics:** import warnings and export losses are listed in notifications, but cannot
  jump to the affected note yet.
- **Icon:** the application icon is a placeholder.

the problem. The manual's troubleshooting chapter lists the messages Wormedit reports and what
to check first.
