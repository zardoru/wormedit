## Current milestone

The Timing pane now exposes the first visual SV-recipe workflow. **New SV recipe** arms a vertical range drag over the Scroll/SV lane; the application converts normalized pointer bounds to exact chart positions, snaps both ends to the timing grid, and opens a revision-bound transient draft. Preview compilation runs only when the draft changes, never per render frame; Apply publishes one insert/update command and Cancel, timing lock, tab/chart/revision changes, or capture loss discard the draft without mutation. The Compose pane now exposes an explicitly armed note-placement Paint tool. Every interchange writer bakes enabled recipes with their configured sampler into an export-only chart copy and clears recipes only in that copy: generic SV and StepMania `SCROLLS` become ordinary instantaneous scroll events, while `SPEEDS` remains the transition family. SSC and osu!mania serialize supported baked events; BMS, BMSON, and SM pass the ordinary events through their existing explicit unsupported-feature checks rather than dropping them. Normalization/impulse primitives, post-processing, Lua generator-backed recipes, and recipe-list/reorder/enable/duplicate UI remain.

A bounded backend-neutral command registry now supplies stable IDs and metadata, USB-HID chords, platform-primary modifiers, standalone remappable shortcut profiles, focus precedence, conflict diagnostics, repeat suppression, and common invocation for menus/toolbars/keys. The SDL frontend now batches bounded same-window physical-key events, fails closed on overflow/focus loss, reports text/IME/Compose-lane focus, and leaves specialized lane-key hold entry on its press/release path. At startup the application atomically applies the optional per-user `shortcuts.json`; malformed or oversized profiles leave defaults intact and a missing first-run profile is silent. Live registry dispatch now routes undo/redo/delete, selection, exact bookmark/section jumps, snap cycling, enabled F-key workspace tabs, timing lock, and stable-ID semantic-layer targeting/membership through existing controller/history boundaries while unsupported new-project/chart, transport, timing-insert/settings, storyboard, and hitsound-paint commands remain disabled. Preference-change saving, remapping UI, command menus/toolbars, and the disabled controllers remain to be wired. The initial hitsound-layering asset subset vendors Phosphor's regular Waveform and Stack SVGs at one pinned upstream commit with its MIT license and provenance; UI composition and GPU upload remain.

Exact measure commands now insert measures, update authored length/meter definitions, and remove empty unreferenced measures while retaining stable identities and updating BMS measure-number projections. Deleting nonempty or globally referenced measures is deliberately rejected until a previewed migration policy exists; global redivision and layout editing remain separate work.

Bounded revision-checked note presentation commands now assign or clear exact UTF-8 labels and manage named colored semantic layers through shared history. Layer CRUD/reordering, explicit note membership assignment/removal/toggle, lock enforcement, and opt-in cleanup on deletion preserve gameplay note data. Both 50,000-note label and layer assignment paths use one chart index pass and remain under the current host's 125 ms interaction target. A separate measure-indexed marker navigator handles exact previous/next beat- or audio-time bookmarks and section boundaries, plus beat-section selection spans; audio-time section selection explicitly requires timing projection. Palette, label, and navigation UI remain.
