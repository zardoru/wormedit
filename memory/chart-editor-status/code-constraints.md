## Current code constraints

The Compose pane now draws bounded scalar projections of the renderer-neutral field scene in Nuklear: layout bands, lanes, exact grid lines, notes/holds, comparison differences, selection styling, cursor geometry, audio-time bookmark/section projections, and live note-paint/rectangle/Space-range previews. Its retained frontend state wires core pointer/keyboard note editing, bounded atomic note-paint drags, rectangle selection, tap-anchor/tap-tail and press-hold/navigate/release Space selection, including blinking exact anchor and tail rows, selection-aware hold resizing, deletion, lane-key holds, vertical wheel scrolling, pointer-anchored wheel zoom, toolbar zoom, page scrolling, and reset actions. Revision-bound valid hold and duration-resize proposals render as noninteractive amber ghosts with subdued committed origins; generic move and invalid/destructive proposal geometry, select-and-drag move/property wiring, horizontal BGM routing, and several richer interaction modes remain unwired. Bookmark/section widgets with their revision-local draft state and the player-preview validator/compositor are separate frontend-private units. Metadata's large editable text/tag/format buffers form one frontend-private state aggregate in their own translation unit; Timing's staged numeric text, exact meter, SV-recipe form/gesture, and marker-drag state follow the same pattern. Audio/Slices likewise owns its revision- and asset-stamped sample-frame offset drag plus pending cancellation. Compose groups bounded keyboard/wheel queues, pointer and keyboard captures, navigation, area/move gesture anchors, chart/revision stamps, and note-label/semantic-layer editor buffers in a fourth tested private state unit. All four reset on initialization and shutdown so no retained pane state leaks across frontend lifetimes. Audio/Slices view validation, asset selection, waveform drawing, and exact offset-drag action composition live in a reusable frontend-private panel unit shared by Metadata and the dedicated Audio tab. Metadata buffer synchronization, validation, widgets, and action composition likewise live in a panel unit that delegates waveform work to Audio/Slices. Timing validation, exact form synchronization, marker/recipe drawing, captured gesture reconciliation, and cancellation action composition form a third panel unit. Compose validation, scalar key/wheel queues, revision/focus reconciliation, action composition, field drawing, and marker widgets now form a fourth panel unit. The shell passes scalar focus/IME/shortcut state and a bounded shared double-click batch, but retains only SDL event normalization, toolkit lifecycle, workspace chrome, and panel routing. Audio-time navigation crosses the marker unit only as typed previous/next actions and scalar availability; exact marker lookup, timing projection, and preview-clock seeking stay in the application layer. Every extracted unit consumes the same backend-neutral C view/action boundary that remains reusable by a future frontend adapter.

The player-like preview is a separate backend-neutral scene rather than Nuklear-owned chart logic. Its immutable chart/revision index precomputes note scroll extents and queries them through a max-end interval tree; each frame consumes only the shared sample-frame clock and emits capped lane, receptor, hold, endpoint, and evaluated storyboard geometry. Preview-only exact timing/scroll options support negative count-in rows without weakening strict editor queries. A bounded cursor over the same immutable schedule resolves all five background/poor/layer/video/storyboard slots, including deterministic replacement and seek reconstruction. `src/sys/player_preview_presenter.cpp` owns the preview's revision caches, storyboard arenas, decode payloads, event-linked diagnostic text, and scalar-view backing storage outside the application shell. Decoder-neutral resource resolution lives in `wormedit::visual_assets`; optional static-image and FFmpeg video targets own separate codec dependencies, byte-bounded CPU LRUs, newest-generation-only jobs, and one serialized reusable video session per project/revision/source. Video jobs are interruptible and revision/exact-time keyed, while exact current/lookahead PTS intervals suppress redundant live requests. `src/ui/nuklear/player_preview.cpp` owns scalar validation and widget composition, while the separate backend-private `player_preview_texture.cpp` owns the fixed 64-entry/256-MiB `SDL_Texture` LRU, keys dynamic video textures by scalar content identity, draws visual layers and layer-aware storyboard sprites, and tears textures down before renderer destruction. Renderer-neutral quad layout performs logical-canvas containment, origin rotation, and signed-scale flips; the Nuklear shell's bounded custom command converts those quads into the same clipped SDL geometry stream as ordinary widgets. Decode/layout/schedule/document policy remains outside the adapter, so a future wxWidgets frontend or offline renderer can own different resources over the same view. Docking persistence and the video encoder remain absent.

The earlier Compose constraint about horizontal BGM routing is resolved: BGM wheel/autoscroll routing, stable-ID tile selection, revision-bound click-audition intent, startup decoder binding, exact clip preparation, bounded generation-aware decode lookahead, headless session/timeline ownership, and SDL device/callback/stream-flush output are wired. The enabled `transport.stop` command now hard-stops an active click preview and clears queued device samples. Recovery/session replacement reconciles the project-scoped audio-asset inventory, hard-stops playback before removing stale decoders, assigns fresh immutable binding identities, and reports assets that cannot be reopened. Property editing, pane-specific drag geometry, and smooth trackpad gesture lifecycle remain unwired.

- T-678 (2026-10-18) removed the unused legacy Chart loader/model and empty Field scaffolding. Their seconds-only conversion and fixed channel maps are no longer application constraints. The live import pipeline and `libotoworm` dependency remain unchanged.
- `src/sys/audio.cpp` still only owns SDL audio subsystem lifetime; private one-shot and chart-preview adapters own their playback streams. The first Audio/Slices waveform overview is wired through the task scheduler and Nuklear draw boundary, while timing-aligned waveform navigation, slice markers, and SDL GPU rendering remain separate.
