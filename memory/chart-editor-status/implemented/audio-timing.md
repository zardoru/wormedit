# Implemented: audio and timing

[Back to the implemented-capability index](../implemented.md).

The pinned miniaudio integration provides headless, bounded, seekable MP3/Ogg-to-float32-stereo decoding at 44.1 kHz without replacing SDL output. A thread-safe decoded-block LRU applies global and per-asset byte/frame limits, keys entries by asset/source revision/block, and uses generation-gated session publication. Bounded waveform analysis builds per-channel peak and RMS pyramids from streamed blocks and chooses detail from the zoom scale; sample-level views use bounded PCM blocks. RMS finalization and higher pyramid reductions use deterministic disjoint parallel ranges above a configurable threshold, capped worker counts and alignment-aware partitions, with a serial fast path for short assets. The headless transport mixes music, BGM, playable keysounds, and clicks at exact sample frames, retires voices, and makes Stop a hard cancellation boundary whose next callback is silent.

A project-owned bounded continuation graph now provides immutable dependency DAGs, typed immutable payloads, ordered fan-in, failure propagation, cooperative cancellation, generation guards, and a fixed `std::jthread` worker pool with a preallocated queue and global outstanding-task cap. It is the standard-library baseline for later render, analysis, load/index, and heavy-export work; priority, work stealing, byte-accounted feature arenas, and dynamic post-submit continuations remain later profiling-driven extensions.

The exact timing index evaluates signed beat-zero offset, BPM changes, delays, stops, and half-open warps in checked rational time. It exposes arrival, event, and departure sides at discontinuities, applies same-row BPM source order, converts seconds/milliseconds/beats/BMS ticks exactly, and performs explicit sample-frame rounding. Each index now resolves a validated discontinuity profile automatically from source family or an explicit override. Canonical editor timing orders BPM, delay, activation, then stop. BMS legacy and BMSON 1.0 retain their presentation activation, BPM, then stop order; StepMania 5.1 has a distinct versionable profile for its BPM, delay, activation, then stop phases even though that order currently matches canonical timing. Parser-backed BMS and native-warp SSC fixtures verify both imported profiles and their exact arrival/event-side frames. Preview compilation retains separate bounded contiguous playable, BGM, BGA, and meter-aware metronome queues and also publishes one bounded cross-family discontinuity stream with stable object IDs and family indexes, so preview, slicing, and future offline rendering do not reconstruct collision order independently. Exact inverse lookup returns fractional absolute rows, maps delay/stop intervals to their boundary row, and makes a collapsed warp plateau's entry/exit choice explicit. A bounded scroll/speed index evaluates signed instantaneous scroll and nonnegative linear beat- or second-based speed transitions with explicit stop/warp clocks and same-row source order. It preintegrates exact cumulative visual displacement at timing, event, and transition boundaries, supports fractional-row binary-seek queries, and fingerprints both timing and scroll/speed sources for safe cache reuse. Exact per-object and bounded bulk SPEEDS transition spans expose rational row/time endpoints and replacement/chart-end clipping through the same evaluator. The Nuklear Timing pane projects those spans through a revision-keyed bounded cache and paints the hovered SPEEDS interval in a light overlay, including seconds-clock behavior through stops and warps. Seek uses binary search and realtime advancement changes only a head index. Optional pre-zero count-in pulses extrapolate the first measure's exact meter grouping and row-zero BPM backward from the row-zero event side; negative-frame clicks are omitted with one bounded diagnostic. A control-thread preview bridge merges playable, BGM, and click heads into bounded reusable transport voice slots, preserves capacity-stalled events for refill, and uses fresh session generations for seek/restart/Stop. Completed transport slots are marked inactive in the callback and reused without vector growth or erase. PCM lookup now invokes the mixer synchronously against retained cache storage instead of copying a block, removing that callback allocation; cache access remains mutex-serialized. A renderer-neutral BGA consumer validates immutable schedules, binary-seeks global and per-layer histories, restores background/poor/layer/video/storyboard state, advances by head without allocation, and generation-gates seek/restart/Stop. Timing fingerprints include the source family and reject stale schedule reuse. The remaining SDL device integration stays a later slice. The 50,000-note schedule remains under its 500 ms hard safety ceiling; the stricter 125 ms interaction target remains an optimization gate on the current host.
