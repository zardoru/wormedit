# Implemented: editing and frontend

[Back to the implemented-capability index](../implemented.md).

The SDL renderer now establishes a logical presentation matching the current logical window size before every Nuklear draw. Fractional high-DPI backbuffers therefore scale the complete UI and clear rather than leaving unpainted right/bottom bands, while Nuklear geometry and SDL pointer input remain in the same coordinate space. The architecture check guards this resize mapping. The workspace now omits the complete recovery block when the controller has neither a candidate nor a diagnostic, returning that otherwise inert height to the active editor.

Compose now starts the iBMSC-oriented density pass: playable columns use a bounded profile-derived width instead of stretching across every spare pixel, an existing BGM lane set receives the remaining horizontal track area, and a responsive left rail projects visible BPM, scroll/SV, speed, stop, delay, warp, kiai, and anchor events against the same viewport as notes and BGM. The adapter labels timing and BGM lanes, rejects note gestures that begin in the timing rail, uses a 16-pixel authoring head instead of a thin grid-like stroke, and carries the lane-profile glyph through renderer-neutral scene geometry so dance layouts receive left/down/up/right heads. The fully wired marker/section and semantic-layer editors remain available in collapsed inspectors rather than permanently consuming canvas height, while the note-label row stays immediately available so note double-click focus behavior is preserved. A true outer-right dock that relocates those secondary editors remains the next UI slice.

Setup now exposes independent SM/SSC file-family, native/legacy timing-syntax,
and syntax-only/StepMania 5.1/Etterna 0.75.1 implementation choices. The
application retains the typed policy outside the adapter, validates it through
the format layer, and transports only bounded enums plus status text through
the scalar frontend boundary. Invalid named-profile combinations remain
visible with an actionable diagnostic instead of being silently normalized.
The stateless Nuklear widgets and validation live in dedicated setup panel/state
units, leaving the same policy and view/action contract reusable by a future
wxWidgets adapter. Export destination and transactional publication remain a
later conversion-pipeline slice.

The modeless player-preview frame now includes deterministic background, poor, layer, video, and storyboard state resolved from the immutable sample-frame schedule. The headless scene validates slot kind, identity, event time, and a renderer-neutral visual-fit policy before publishing them through the scalar frontend contract. Current static-image resources decode asynchronously into immutable project/revision-keyed RGBA payloads. The application explicitly selects SDL3's `gpu` renderer, Nuklear composes through that renderer, and the preview adapter owns a separate 64-entry/256-MiB `SDL_Texture` LRU over the renderer's `SDL_GPUDevice`; the old OpenGL context, uploader, and link dependency are gone. The adapter applies shared stretch/contain/cover geometry, draws ready layers in stable draw/source order behind translucent lanes, and releases every texture before renderer shutdown. Contain is the current default, preserving aspect ratio with letterboxing, while cover uses deterministic centered whole-pixel source crops. Upload and composition return bounded typed per-resource failures; the overlay reports allocation, GPU rejection/out-of-memory, size, identifier, image, or layout failures while still drawing unaffected layers and chart geometry. Forward advancement and backward seek use the same bounded BGA cursor. Asset resolution, decoding, layout policy, schedule policy, and document ownership stay outside the adapter so wxWidgets and offline-video consumers can reuse them without inheriting SDL or Nuklear types.

A frontend-neutral interaction controller now owns exact cursor/snap movement, explicit typed selection, layout-transition remapping, command-backed tap placement/removal, two-step cross-measure hold preview/commit/cancel, exact selected-note duration-delta resizing with hold-to-tap collapse, atomic cursor/selection deletion, undo/redo, content-clamped scrolling, and pointer-anchored zoom that changes visual note spacing without changing authored positions. StepMania-style held lane keys extend or contract a live tail as controller-owned cursor movement advances, and release commits one atomic tap/hold edit. Alt/Option pointer drag provides the equivalent mouse gesture. Tail dragging applies one exact delta to all selected notes, collapse at each head yields a tap, and Escape, focus loss, modifier release, or pointer-capture loss cancels without mutation. Pending gestures reject stale revisions and retain their preview after recoverable failures. Whole-selection lane assignment and deterministic uBMSC-style successive Shift + lane assignment validate target layouts/collisions atomically; successive assignment consumes one selected note and returns its keysound audition request. The 50,000-note assignment fixture completes near 0.11 seconds warm on the current host, below the 125 ms discrete-interaction target. Exact pixel/row mapping and revision-bound per-measure hit buckets expose deterministic lane, note, hold-head, hold-body, and cross-measure hold-tail targets. Typed object hover shares the selection interval tree for bounded row/span lookup, resolves details by binary-searching stable typed IDs, produces backend-neutral tooltips, and issues a type-specific edit request only after a same-object double click within the configured time/slop while revision, focus, and pointer capture remain valid. Pointer-captured paint interpolates newly crossed snap cells, suppresses duplicates, toggles existing taps, enforces a 50,000-cell cap, and commits or rejects the whole gesture as one command. Pointer rectangle selection normalizes every drag direction, uses exact zoom/scroll and lane-column geometry for notes, selects note heads/tails/hold bodies, and supports replace/add/toggle modes through a revision-bound captured preview. Two-point Space selection captures the exact cursor anchor and selection mode, previews the inclusive row range during navigation, and commits on the second Space press; reversed cross-measure ranges and hold head/tail/body intersections use the same bounded span index. Explicit scopes now extend both selectors to BGM, BPM/pause/warp/scroll/speed/kiai/anchor timing objects, BGA, and beat-anchored bookmarks/sections using typed object identities. Non-note rectangle selection currently has only vertical row geometry, and audio-time markers await a timing-index projection. Long-span candidates are narrowed through a begin-row-sorted span list and max-end interval tree; both 50,000-note and 50,000-BGM sparse-range fixtures remain bounded. A renderer-neutral grid service produces exact measure, authored beat/group, and active-snap lines—including fractional row positions—and suppresses only visually dense subdivisions as zoom decreases. A revision-bound field-scene index/composer turns visible layout bands, split-stage lane columns, exact grid lines, comparison-difference backgrounds, notes/transition-split hold bodies, selection, and cursor state into bounded backend-neutral screen geometry; its max-end tree narrows sparse 50,000-note viewports and zoom changes spacing without changing rows. An exact cross-difficulty comparator aligns charts with different row resolutions in standard-measure space, compares lane/layout and note/hold signatures with optional sound/layer/label semantics, detects chart-duration differences, and returns only bounded differing rows for synchronized yellow-pane backgrounds. A headless viewport-input controller accumulates fractional smooth/coarse two-axis deltas, keeps pane routing stable for a gesture, isolates BGM horizontal motion, applies configurable natural direction/sensitivity, produces cursor-anchored zoom requests, continues bounded momentum, and implements interruptible middle-button autoscroll without mutating authored positions. A headless seven-tab workspace controller retains stable active/comparison difficulties, shared transport and undo/redo/dirty summaries, and isolated logical focus across Setup, Metadata, Timing, Compose, Audio/Slices, and Compare/Validate while exposing Storyboard as a disabled placeholder. The checked `WORMEDIT_UI_BACKEND` cache enum selects one private frontend target, direct Nuklear lifecycle/widgets and a responsive shell for the real workspace view now live under `src/ui/nuklear`, and an architecture test prevents toolkit symbols from entering core/controller sources. The Metadata pane now has revision-checked edit controls for shared title/artist/tags, the selected chart's name/author, and generic ordered format fields, while the recovery panel exposes explicit recovery actions. Audio/Slices retains its sample-frame-exact offset-drag identity, preview delta, and cancel requests in a frontend-private state unit that resets at frontend initialization and shutdown. Other substantive pane editors, recovery visual polish, and remaining field-scene input/rendering remain. The continuous-frame target still needs calibrated performance jobs.

Audio/Slices view validation, asset selection, waveform rendering, and exact offset-drag action composition are isolated in a frontend-private panel unit reused by Metadata and the dedicated Audio tab. It receives only a Nuklear context, scalar focus state, backend-neutral view, and typed action; transport, decoder, document, and timing policy remain outside it.

A bounded metadata editor and its Nuklear pane now commit shared title/artist/tags, selected-difficulty name/author/exact optional signed-rational rating, and generic ordered format-field insert/replace/delete edits through revision-checked commands while preserving imported source identities. Name, author, and rating are applied atomically; rating components are bounded and validated without reducing the authored rational, and an explicit unset preserves other staged fields. The pane's retained title, artist, chart, rating, offset, ordered-tag, and format-field buffers are grouped in a frontend-private state unit and reset at frontend initialization and shutdown, preventing state leakage across frontend lifetimes and reducing shell-global context. Its buffer synchronization, parsing, widgets, and typed action composition now reside in a separate frontend-private panel that receives only the Nuklear context, scalar focus state, backend-neutral metadata view, and workspace action; waveform interaction delegates to the reusable Audio/Slices panel. The pane edits one selected difficulty and leaves excessive rows read-only or hidden without dropping document data. It does not yet expose inheritance/override controls, batch across difficulties, or provide typed per-format forms. The startup shell resolves/creates the SDL per-user recovery directory, scans it, and renders explicit Inspect/Recover/Save-as/Discard/Quarantine actions. The periodic autosave loop publishes one immutable dirty snapshot at a time through the bounded worker, reports failures, and protects recovery/session replacement while publication is in flight.

The BMSON 1.0 normative rule for `info.resolution` is now explicit: zero, null, or omission selects the default 240 pulses per quarter note, while a negative numeric value uses its checked absolute magnitude; every spelling retains source provenance. Wrong JSON types and invalid pulse values remain negative cases. This corrects the earlier reference-note wording that treated zero as invalid.

Up/Down cursor movement, Delete/Backspace, undo/redo, lane-key tap/hold entry, whole-selection and Shift-successive lane assignment, Alt/Option hold creation, existing-note duration resizing, selected-note duration deltas, zoom, page scrolling, vertical coarse/smooth wheel scrolling, and pointer-anchored primary-modifier wheel zoom all dispatch through the headless controller. Exact cursor and page navigation use a tested 25–75% mobile-head comfort band: crossing either boundary adjusts the one shared viewport, and the chart-wide edit-head line remains aligned across the timing rail, notes, and BGM. SDL wheel direction is normalized at the frontend boundary and fractional deltas remain intact. The scalar frontend contract and Nuklear adapter reserve a responsive right-hand pane when BGM lanes exist, keep note gestures and hit geometry out of it, and render labeled alternating source lanes plus bound/unbound and selected event tiles under the shared grid/edit head. Wheel input over that pane and its middle-click autoscroll route to a chart-scoped retained horizontal offset, clamp after resize or lane changes, and leave shared cursor-anchored time zoom available. Smooth trackpad gesture begin/end capture and momentum remain to be connected at the SDL boundary. Focus/modifier/capacity loss cancels captured gestures. Its bounded key/wheel queues, pointer/keyboard captures, navigation and selection anchors, chart/revision stamps, and label/layer editor buffers are grouped in a tested frontend-private state unit with complete lifecycle reset. View validation, scalar event ingestion, chart/revision/focus reconciliation, typed action batching, all Compose widgets, and field rendering now reside in a dedicated frontend-private panel; the shell supplies normalized SDL values and shared click/shortcut context without exposing document or controller policy. The workspace exposes the bounded full BMS control-tree outline plus scalar RANDOM/SWITCH choices, including sparse values, unresolved reachable controls, inactive nested controls, and truncation state. The Timing pane now exposes a revision-bound active-grid selector over exact supported denominators, with a one-row resolution fallback; its selection drives marker insertion/movement, default warp length, and SV-recipe range snapping, and is disabled while a staged edit exists. It draws the same bounded exact active-snap, beat/group, and measure grid hierarchy as the shared field-grid service behind all marker lanes. Durable parametric SV/`SCROLLS`/`SPEEDS` recipes now retain exact intervals, built-in constant/linear/exponential/bump parameters, bounded fixed/adaptive sampling policies, enabled state, stable order, and SPEEDS transition settings. Native version-1 projects serialize only those editable recipes and accept older charts with the field absent; sampled points are transient and never enter the document. The compiler evaluates authored scroll/speed values as a baseline and multiplies every overlapping enabled recipe pointwise with half-open boundary ownership. A renderer-neutral start/end/whole-span drag controller snaps unsnapped hits to the active exact grid, normalizes crossed endpoints, preserves span length when translating, keeps updates preview-only, and commits one revision-checked undo command. The draft API adds preview/apply/cancel around new or existing recipes, substitutes edits at their stable vector slot without copying the chart, and returns raw plus composed transient batches. The Timing pane wires new-recipe area selection, exact built-in parameter/sampling controls, range reselection, and bounded raw/composed line previews to that API. Every interchange writer bakes enabled recipes with their configured sampler into an export-only chart copy and clears recipes only in that copy: generic SV and StepMania `SCROLLS` become ordinary instantaneous scroll events, while `SPEEDS` remains the transition family. SSC and osu!mania serialize supported baked events; BMS, BMSON, and SM pass the ordinary events through their existing explicit unsupported-feature checks rather than dropping them. Normalization/impulse primitives, post-processing, Lua generator-backed recipes, and recipe-list/reorder/enable/duplicate UI remain.
