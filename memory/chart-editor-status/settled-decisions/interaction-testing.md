# Settled decisions: interaction and testing

[Back to the settled-decision index](../settled-decisions.md).

- Core model, timing, audio, and editor-controller behavior must be headless-testable to prevent regressions, with CI on all three desktop targets.
- Every parser/converter/interaction contract needs positive and negative regression cases; rejected input must not partially mutate documents or outputs.
- Use Catch2 v3 for C++ tests. Gate the test tree with CMake's `BUILD_TESTING`, link test executables to `Catch2::Catch2WithMain`, and register individual cases through `catch_discover_tests(... DISCOVERY_MODE PRE_TEST)` so CTest and CI can discover and label them.
- Support direct mouse selection plus both StepMania-style Space range gestures: press-hold while navigating and release to commit, or tap to arm a flashing anchor row and tap again at the tail.
- Support snapped mouse placement for notes and holds, transactional paint drag, visible hover state for every editable chart object, and same-object double-click property editing such as BPM values. Route these through the same validated undo commands as keyboard input. Draw proposal-derived ghosts for every captured move, resize, hold, range, recipe, timing, BGM, and BGA transform, distinguishing valid, destructive-normalizing, and invalid results.
- Bind Alt/Option + mouse press-drag to bidirectional snapped hold entry with a live head/body/tail preview and release-to-commit; crossing the origin swaps the moving endpoint, covered taps are removed, and touching/overlapping ordinary holds merge through one atomic command.
- When the Alt/Option-drag reference note is selected, apply its exact duration delta to every selected playable note as one previewed atomic resize while preserving start rows and relative duration differences.
- Contract a hold to one row to convert it back into a regular tap; normalize a drag across the origin rather than rejecting it as a reversed duration.
- Delete the active-lane cursor note when no selection exists, or delete the validated selected object set atomically without deleting shared resources.
- Page by a configurable positive number of measures, default one, with Page Up/Down on Windows/Linux and Option+Up/Down on macOS. Controller-owned hold timing starts repeat after one second and accelerates after three seconds.
- Support coarse wheel and smooth two-axis trackpad viewport scrolling with fractional accumulation, natural direction, stable pane routing, independent BGM horizontal scroll, configurable sensitivity, cursor-anchored zoom, and interruptible momentum. Scrolling never emits chart edits.
- Middle-click latches visible two-axis autoscroll to the starting pane; this is especially for horizontally wide BMS BGM-lane banks. A second middle click, Escape, focus loss, modal opening, or normal editing click cancels it without emitting an edit.
- Support profile-driven lane-key entry. Default the left/only stage to number keys and the right double-play stage to the QWERTY row; use `Q A W S E D R F` and `H U J I K O L P` for BMS 14K.
- Support StepMania-style keyboard holds: press and retain a lane key, navigate in either direction on the exact grid to move the appropriate endpoint, and release to commit through the shared collision/union hold command; a release without extension remains tap entry. Pressing a lane key on an occupied ordinary tap/hold removes the whole object.
- With a selection, a bare lane key moves all selected playable notes and keeps them selected. Shift + lane follows uBMSC: atomically move the first selected playable note in deterministic order, deselect/audition it, and retain the rest for successive assignment. Failed moves retain data and selection.
- Up/Down repeatably move the edit cursor and every aligned pane beneath one full-width edit head by the active exact snap; held on-screen Up/Down controls invoke the same command. Left/Right cycle a configurable StepMania-style snap list after filtering out fractions unsupported by the current resolution.
- Refactor Compose into the compact hybrid BMSE/iBMSC/StepMania surface: measure numbers and toggleable timing lanes on the left, bounded square indexed playable tiles in the center, BGM/BGA tracks on the right, and collapsible sound controls. Timing reuses the same grid/field projection; BMS starts with a sparse virtual `#000`–`#999` canvas; profile defaults choose upscroll/downscroll and remain user-overridable.
- Add a compact placement toolbar with armable create-only auto-increment for Samples/BGM/BGA. Advance in stable eligible resource order only after successful insertion, stop by default at exhaustion, and leave the ephemeral picker unchanged by assign/replace/delete, failure, preview, undo, or redo.
- Render profile-default Metadata fields as typed controls, add previewed per-chart key-count/profile migration, and support transactional song-file copy/drop/relink to project/export directories. Keep song/music and canonical offset in one cross-cutting Audio and synchronization group rather than format-specific rows; selecting/relinking an audio stream immediately reuses or schedules cancellable incremental waveform generation, and Compose/Metadata share one sample-frame-exact ghosted waveform-drag offset command. Keep compact content-sized active tabs/menus/status, bounded form margins, hidden empty recovery chrome, and reusable double-click-select-all text fields.
- Make BPM entry decimal-first across pseudo-notes, properties, marker labels, and keyboard editing. Parse user decimal spelling directly to exact rationals, offer `0.01` default/coarse/fine stepping and advanced fraction access, and mark rounded display of non-terminating derived values without changing the exact value on open/close.
- Use a two-octave virtual-piano physical-key map for BMSON-only Keyboardmania-style 24K. For BMSON 48K, reuse it for the visibly focused 24-key stage, with remapping and later direct MIDI/multi-device bindings available. Emit BMSON `generic-24keys`/`generic-48keys` with lanes ordered left-to-right; do not map these modes to BMS/MGQ channels.
- Support synchronized side-by-side difficulty preview, marking different musical rows with a yellow background.
- Support a versioned native rich clipboard format plus BMSE and iBMSC clipboard compatibility with paste preview and loss/conflict diagnostics.
